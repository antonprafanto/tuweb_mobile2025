SLIDE 14 • MODUL 3 BMP UT

Deklarasi Emits Bertipe: defineEmits<T>()

Mengunci nama event dan tipe parameter payload yang dipancarkan anak ke induk.

📘 PANDUAN PRAKTIKUM MAHASISWA

🛠️ Alat yang Digunakan: Google Chrome / Peramban Web Modern.

🎯 Cara Menguji Interaksi: Klik tombol merah "🗑️ Hapus Mata Kuliah". Amati bagaimana sinyal custom event terpancar ke komponen induk dengan membawa payload ID mata kuliah bertipe string, lalu memicu pesan log hijau di bawah.

💡 Apa yang Terjadi di Balik Layar: Di JavaScript biasa, pemanggilan emit('hapus-mk', 123) bisa salah tipe data tanpa peringatan. Dengan generic defineEmits<{ (e: 'hapus-mk', id: string): void }>(), TypeScript akan memprotes jika nama event typo atau jika tipe payload ID tidak cocok.

📐 Alur Sinyal Events Up Bertipe: Komponen Anak ke Induk

📢 Pancaran Sinyal Bertipe (Type-Safe Events)

STSI4303 - Pemrograman Bergerak (3 SKS)
{{ pesanLog }}

💡 Kode TypeScript defineEmits:

// DI DALAM KOMPONEN ANAK
<script setup lang="ts">
// Deklarasi event bertipe ketat:
const emit = defineEmits<{
  (e: 'hapus-mk', id: string): void;
  (e: 'ubah-nilai', id: string, nilaiBaru: NilaiHuruf): void;
}>();

const triggerHapus = (): void => {
  emit('hapus-mk', 'STSI4303'); // Payload wajib bertipe string!
};
</script>
