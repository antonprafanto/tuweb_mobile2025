SLIDE 09 • MODUL 3 BMP UT

Integrasi Vue 3 & TypeScript: <script setup lang="ts">

Membangun komponen Single File Component modern dengan dukungan type inference otomatis.

📘 PANDUAN PRAKTIKUM MAHASISWA

🛠️ Alat yang Digunakan: Google Chrome, Visual Studio Code (Ekstensi Vue - Official Volar).

🎯 Cara Menguji Interaksi: Pelajari kode Single File Component (SFC) pada panel kiri dan uji interaksi tombol status pada panel kanan. Klik tombol "Ubah Status Online" untuk melihat reaktivitas state bertipe Dosen.

💡 Apa yang Terjadi di Balik Layar: Dengan menambahkan atribut lang="ts" pada tag <script setup>, kita tidak perlu lagi menulis kode panjang (*boilerplate*) seperti defineComponent() atau export default { ... }. Seluruh variabel dan fungsi diekspos langsung ke template dengan proteksi tipe penuh!

📐 Anatomi Single File Component (SFC) Vue 3 Bertipe TypeScript

📚 Referensi Modul: BMP UT STSI4303 Modul 3: "SFC Vue 3 dengan TypeScript" • Vue.js 3 Official Guide: "TypeScript with Composition API — <script setup>".

📄 Berkas SFC: ProfilTutor.vue

<script setup lang="ts">
import { ref } from 'vue';

// 1. Definisikan Interface
interface Dosen {
  nama: string;
  nidn: string;
  isOnline: boolean;
}

// 2. Typing State Reaktif Eksplisit
const dosen = ref<Dosen>({
  nama: 'Anton Prafanto, S.Kom., M.T.',
  nidn: '0012058401',
  isOnline: true
});

const toggleOnline = (): void => {
  dosen.value.isOnline = !dosen.value.isOnline;
};
</script>
