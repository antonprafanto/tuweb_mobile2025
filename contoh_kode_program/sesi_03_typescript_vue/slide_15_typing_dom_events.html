Penanganan DOM Events Bertipe (Event, KeyboardEvent, HTMLInputElement)

Mengakses properti event.target.value secara aman menggunakan Type Casting.

📘 PANDUAN PRAKTIKUM MAHASISWA

🛠️ Alat yang Digunakan: Google Chrome / Peramban Web Modern.

🎯 Cara Menguji Interaksi: Ketikkan NIM Anda pada kolom input di bawah. Perhatikan bahwa setiap kali tombol ditekan, event ditangkap dan karakter terakhir serta isi masukan diperbarui secara real-time.

💡 Apa yang Terjadi di Balik Layar: Di TypeScript murni, variabel event.target hanya bertipe generik EventTarget yang tidak memiliki properti .value. Oleh karena itu, kita melakukan penegasan tipe (*Type Assertion / Casting*): (event.target as HTMLInputElement).value agar VS Code mengizinkan pembacaan input formulir secara sah.

💡 Solusi Type Casting di TypeScript:

// Tanpa TypeScript casting, e.target.value akan dianggap error!
const handleInput = (event: Event): void => {
  // Lakukan Type Assertion (as HTMLInputElement)
  const target = event.target as HTMLInputElement;
  console.log('Nilai input:', target.value);
};

// Khusus Event Keyboard:
const handleKey = (event: KeyboardEvent): void => {
  if (event.key === 'Enter') {
    console.log('Pengguna menekan tombol Enter!');
  }
};
