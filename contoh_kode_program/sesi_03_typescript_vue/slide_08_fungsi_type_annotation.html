Anotasi Tipe Fungsi: Parameter Ketat & Return Type Eksplisit

Mencegah salah urutan argumen dan menjamin tipe nilai yang dikembalikan fungsi kalkulasi.

📘 PANDUAN PRAKTIKUM MAHASISWA

🛠️ Alat yang Digunakan: Google Chrome / Peramban Web Modern.

🎯 Cara Menguji Interaksi: Ubah angka Beban SKS (misal: 3) dan pilih Nilai Huruf (misal: A). Perhatikan kotak hasil hijau langsung memperbarui Nilai Mutu (3 SKS × 4.0 = 12.00).

💡 Apa yang Terjadi di Balik Layar: Fungsi kalkulasi akademik adalah inti dari Tugas 1. Dengan signature ketat function hitungMutu(sks: number, huruf: NilaiHuruf): number, TypeScript menjamin bahwa kita tidak bisa tertukar memasukkan parameter atau mengembalikan teks secara tidak sengaja.

📐 Alur Kontrak Fungsi: Parameter Input Ketat Menghasilkan Return Type Pasti

🧮 Fungsi Hitung Mutu: hitungMutu(sks, huruf)

NILAI MUTU (SKS × BOBOT):
{{ totalMutu.toFixed(2) }}
Formula: {{ sks }} SKS × {{ bobot }} = {{ totalMutu.toFixed(2) }}

💡 Anotasi Lengkap Fungsi di TypeScript:

// Definisi fungsi kalkulasi resmi:
function hitungNilaiMutu(sks: number, huruf: NilaiHuruf): number {
  const bobotMap: Record<NilaiHuruf, number> = {
    'A': 4.0, 'B': 3.0, 'C': 2.0, 'D': 1.0, 'E': 0.0
  };
  return sks * bobotMap[huruf];
}

// Void Function (Tanpa Nilai Balik):
function logAktivitas(pesan: string): void {
  console.log(`[LOG UT] ${pesan}`);
}
