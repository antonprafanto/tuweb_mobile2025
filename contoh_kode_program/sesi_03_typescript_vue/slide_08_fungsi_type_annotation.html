Anotasi Tipe Fungsi: Parameter Ketat & Return Type Ekplisit

Mencegah salah urutan argumen dan menjamin tipe nilai yang dikembalikan fungsi kalkulasi.

🧮 Fungsi Hitung Mutu: hitungMutu(sks, huruf)

NILAI MUTU (SKS x BOBOT):
{{ mutu }} Poin

💡 Anotasi Fungsi di TypeScript:

// Definisi Fungsi dengan Parameter & Return Type Eksplisit
function hitungMutu(sks: number, huruf: NilaiHuruf): number {
  const bobotMap: Record<NilaiHuruf, number> = {
    'A': 4.0, 'B': 3.0, 'C': 2.0, 'D': 1.0, 'E': 0.0
  };
  return sks * bobotMap[huruf]; // Wajib mengembalikan number!
}
