SLIDE 12 • MODUL 3 BMP UT

Type Safety pada Properti Terkalkulasi: computed<T>()

Menjamin kembalian perhitungan nilai dan predikat akademik selalu sesuai tipe data.

📘 PANDUAN PRAKTIKUM MAHASISWA

🛠️ Alat yang Digunakan: Google Chrome / Peramban Web Modern.

🎯 Cara Menguji Interaksi: Perhatikan kotak statistik kalkulasi di bawah. Nilai Total SKS (number), Nilai IPS (number), dan Predikat (string) dihitung secara otomatis oleh fungsi computed<T>().

💡 Apa yang Terjadi di Balik Layar: Dengan menulis const totalSks = computed<number>(...), TypeScript mengunci bahwa variabel tersebut hanya mengekspos tipe data numerik. Properti computed bersifat *read-only*, sehingga kita tidak dapat mengubah nilainya dari luar secara sengaja.

📐 Alur Dependency Tracking & Type Inference pada computed<T>

📊 Ringkasan Akademik Hasil Kalkulasi:

TOTAL SKS (number)
{{ totalSks }} SKS
INDEKS PRESTASI (number)
{{ ips.toFixed(2) }}
PREDIKAT KELULUSAN (string)
{{ predikat }}

💡 Contoh Kode TypeScript:

// 1. Computed yang mengembalikan tipe number murni:
const totalSks = computed<number>(() => {
  return listMk.value.reduce((total, mk) => total + mk.sks, 0);
});

// 2. Computed yang mengembalikan tipe string predikat:
const predikat = computed<string>(() => {
  return ips.value >= 3.5 ? 'Dengan Pujian' : 'Sangat Memuaskan';
});
