Generics pada Koleksi: Array<T> vs T[] untuk Manipulasi Aman

Memastikan setiap elemen di dalam array selalu mematuhi interface secara seragam.

📘 PANDUAN PRAKTIKUM MAHASISWA

🛠️ Alat yang Digunakan: Google Chrome / Peramban Web Modern.

🎯 Cara Menguji Interaksi: Klik tombol "Filter SKS >= 3" untuk memfilter koleksi mata kuliah. Kemudian klik "Tampilkan Semua (Reset)". Perhatikan bagaimana seluruh iterasi tabel mengenali kolom kode, nama, dan sks dengan keamanan tipe data penuh.

💡 Apa yang Terjadi di Balik Layar: Di JavaScript biasa, array bisa berisi data campur aduk (angka, teks, objek acak). Dengan sintaks generik Array<MataKuliah> atau MataKuliah[], TypeScript mengunci bahwa SETIAP elemen di dalam array wajib berwujud objek MataKuliah. Operasi seperti .filter() dan .reduce() pun otomatis mendapatkan auto-complete cerdas di VS Code!

💡 Perbandingan Deklarasi Generik di TypeScript:

// 1. Sintaks Kurung Sudut Generik Resmi:
const listA: Array<MataKuliah> = [];

// 2. Sintaks Shorthand (Paling Populer & Bersih):
const listB: MataKuliah[] = [];

// Keduanya identik 100% dalam keamanan type checking!
