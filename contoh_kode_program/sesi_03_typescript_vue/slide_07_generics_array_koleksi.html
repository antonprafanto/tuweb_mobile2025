Generics pada Koleksi: Array<T> vs T[] untuk Manipulasi Aman

Memastikan setiap elemen di dalam array selalu mematuhi interface secara seragam.

📚 Koleksi Mata Kuliah Bertipe: Array<MataKuliah>

💡 Dua Cara Menulis Generic Array di TypeScript:

// Format 1: Sintaks Tanda Kurung Siku (Shorthand)
const listNilai: MataKuliah[] = [ ... ];

// Format 2: Sintaks Formal Generics (Array<T>)
const listKRS: Array<MataKuliah> = [ ... ];

// Keuntungan Generics: VS Code langsung tahu properti .sks saat di-reduce!
const totalSks = listKRS.reduce((total, item) => total + item.sks, 0);
