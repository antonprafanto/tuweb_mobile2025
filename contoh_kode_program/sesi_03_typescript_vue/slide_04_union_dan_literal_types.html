Union Types & Literal Types: Membatasi Nilai Sah secara Mutlak

Mencegah nilai acak pada status akademik dan nilai mutu mata kuliah.

📘 PANDUAN PRAKTIKUM MAHASISWA

🛠️ Alat yang Digunakan: Google Chrome / Peramban Web Modern.

🎯 Cara Menguji Interaksi: Pilihlah salah satu opsi pada dropdown Nilai Huruf (A, B, C, D, E) dan Status Registrasi. Perhatikan bagaimana nilai yang dipilih langsung mengupdate lencana status di bawah. Di TypeScript, input di luar 5 huruf resmi ini akan langsung ditolak oleh compiler.

💡 Apa yang Terjadi di Balik Layar: Tipe data string biasa mengizinkan kata sembarangan seperti "A+" atau "Hampir Lulus". Dengan Literal Type type NilaiHuruf = 'A' | 'B' | 'C' | 'D' | 'E', kita mengunci nilai hanya pada himpunan resmi yang diakui Universitas Terbuka untuk perhitungan IPS Tugas 1!

📐 Mekanisme Union Type: Penguncian Himpunan Nilai Sah

🎓 Pemilihan Status Akademik & Nilai Mutu

Status Terpilih: {{ statusMhs.toUpperCase() }} (Nilai: {{ pilihanNilai }})

💡 Kode Definisi TypeScript:

// 1. Literal Types: Hanya mengizinkan teks yang terdaftar
export type NilaiHuruf = 'A' | 'B' | 'C' | 'D' | 'E';
export type StatusMahasiswa = 'Aktif' | 'Cuti' | 'Lulus';

// 2. Union Types pada properti:
export interface RiwayatNilai {
  kodeMk: string;
  nilai: NilaiHuruf;        // Menolak jika diisi selain A, B, C, D, E
  status: StatusMahasiswa;   // Menolak jika diisi "Pending" atau kata sembarangan
}
