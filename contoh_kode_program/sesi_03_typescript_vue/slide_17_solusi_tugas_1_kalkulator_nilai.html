Studi Kasus Interaktif: Kalkulator Nilai & IPK Mahasiswa UT

Implementasi acuan praktikum mandiri berbasis TypeScript Model & Vue 3 Composition API.

📘 PANDUAN STUDI KASUS PRAKTIKUM MANDIRI

🛠️ Alat yang Digunakan: Google Chrome (Mode Desktop atau Mode Simulator Ponsel Ctrl + Shift + M).

🎯 Langkah Uji Coba Mandiri: 1. Masukkan kode mata kuliah (misal: STSI4303), nama mata kuliah, beban SKS (1–6), dan pilih nilai huruf (A/B/C/D/E).
2. Klik tombol "+ Tambah ke Daftar Nilai".
3. Perhatikan pemutakhiran otomatis Total SKS, Total Nilai Mutu, dan Indeks Prestasi Semester (IPS) beserta Predikat Akademik.
4. Klik tombol "🗑️ Hapus" pada salah satu baris tabel untuk menguji reaktivitas pengurangan nilai.

💡 Apa yang Terjadi di Balik Layar: Seluruh arsitektur dibangun di atas interface MataKuliah dan interface MahasiswaUT. Operasi kalkulasi IPS memanfaatkan computed<number>() murni yang mengeliminasi kebutuhan looping manual saat data berubah.
