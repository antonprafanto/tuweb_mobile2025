Tipe Data Primitif TypeScript & Jebakan 'any' Hazard

Memahami tipe bawaan dan alasan mengapa kata kunci any diharamkan di standar industri.

📘 PANDUAN PRAKTIKUM MAHASISWA

🛠️ Alat yang Digunakan: Google Chrome / Peramban Web Modern, VS Code.

🎯 Cara Menguji Interaksi: Ketikkan angka pada kolom input totalSks: number (misal: 20). Perhatikan badge hijau muncul menandakan data valid. Sekarang cobalah ketikkan teks seperti dua puluh atau kosongkan kolom, seketika muncul pesan peringatan merah Type Error.

💡 Apa yang Terjadi di Balik Layar: TypeScript memiliki 3 tipe primitif utama: string, number, dan boolean. Jangan sekali-kali tergoda memakai tipe any hanya untuk membungkam pesan error, karena any menonaktifkan seluruh sistem proteksi dan membuat aplikasi rentan crash di tangan pengguna!

📐 Visualisasi Proteksi: Tameng Tipe Primitif vs Bahaya Lubang Hitam 'any'

🧪 Simulator Validasi Tipe Data (Type Checking)

Masukkan nilai pada kolom di bawah untuk menguji validasi tipe data secara langsung:

❌ Type Error: Type 'string' is not assignable to type 'number'! Nilai "{{ inputSks }}" bukan angka valid.
✅ Type Valid: Nilai {{ Number(inputSks) }} sah sebagai tipe data number.

🚫 Mengapa Dilarang Memakai any?

// ❌ ANTI-PATTERN: Menggunakan 'any' mematikan seluruh fungsi TypeScript!
let dataNilai: any = "Lulus";
dataNilai = 4.0;
dataNilai.toUpperCase(); // Runtime Crash! 4.0 tidak punya method toUpperCase()

// ✅ BEST PRACTICE: Gunakan tipe eksplisit atau Union Types
let nilaiAngka: number = 4.0;
let statusLulus: boolean = true;
let prodi: string = "S1 Sistem Informasi";
💡 Aturan Emas Dosen: Menggunakan any sama saja dengan kembali ke JavaScript purba. Jika data memang belum diketahui bentuknya saat menerima dari server eksternal, gunakan tipe unknown disertai pemeriksaan type narrowing (`typeof`)!
