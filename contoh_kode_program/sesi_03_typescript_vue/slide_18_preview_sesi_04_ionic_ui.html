SLIDE 18 • JEMBATAN MENUJU SESI 04

Menuju Ekosistem Mobile Asli: Mengapa Butuh Ionic Framework?

Selamat tinggal tombol HTML biasa, selamat datang antarmuka khas smartphone (Material Design & iOS).

1. ELEMEN HTML WEB BIASA

Tampilan Datar Desktop

Elemen default peramban terasa kaku, tidak memiliki efek getaran/ripple sentuhan, dan tidak responsif seperti aplikasi mobile asli.

Kartu Berita Web Biasa

Konten teks standar tanpa animasi mobile.

2. IONIC FRAMEWORK (MOBILE UI)

Kenyamanan Smartphone Asli

Ionic menyediakan komponen UI siap pakai dengan efek sentuhan Material Design (Android) dan Cupertino (iOS) secara otomatis!

📲 Tombol Mobile Asli (ion-button) Sesi 04 Pekan Depan Antarmuka Mobile Siap Pakai Di Sesi 04, kita akan membedah ion-app, ion-page, ion-header, ion-content, dan navigasi tumpukan kartu mobile!

🚀 Apa yang Akan Kita Pelajari di Sesi 04?

// Mengimpor Komponen Ionic di Vue 3 (Sesi 04):
import { IonPage, IonHeader, IonToolbar, IonTitle, IonContent, IonButton } from '@ionic/vue';

// Template dengan arsitektur navigasi tumpukan mobile:
<ion-page>
  <ion-header>
    <ion-toolbar color="primary">
      <ion-title>MyUT Mobile</ion-title>
    </ion-toolbar>
  </ion-header>
  <ion-content class="ion-padding">
    <ion-button expand="block" @click="keHalamanBerikutnya">Masuk ke Kampus</ion-button>
  </ion-content>
</ion-page>
