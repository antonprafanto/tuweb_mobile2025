SLIDE 18 • JEMBATAN MENUJU SESI 04

Transisi Menuju Sesi 04: Komponen Antarmuka Mobile Asli Ionic UI

Membandingkan batasan elemen web standar HTML dengan kenyamanan komponen smartphone Ionic.

📘 PANDUAN PRAKTIKUM MAHASISWA

🛠️ Alat yang Digunakan: Google Chrome (Coba aktifkan mode ponsel: Tekan F12 lalu Ctrl + Shift + M).

🎯 Cara Menguji Interaksi: Sentuh / klik tombol HTML biasa pada panel kiri, lalu bandingkan dengan tombol <ion-button> pada panel kanan. Rasakan efek animasi sentuhan (*ripple effect*) dan kenyamanan tampilan kartu mobile asli.

💡 Apa yang Terjadi di Balik Layar: Di Sesi 01 s.d. Sesi 03, kita menggunakan elemen HTML5 konvensional. Pekan depan di Sesi 04, kita akan beralih ke Ionic Framework yang secara otomatis menyesuaikan tampilan tombol, header, dan kartu sesuai platform perangkat (Material Design di Android dan Cupertino di iOS).

📐 Evolusi Perkuliahan: Dari Fondasi Web Standards Menuju Mobile Asli Ionic

📚 Referensi Modul: BMP UT STSI4303 Modul 4: "Dasar-Dasar Ionic Framework & Navigasi Mobile" • Ionic Framework Docs: "Cross-Platform UI Components".
1. ELEMEN HTML WEB BIASA

Tampilan Datar Desktop

Elemen default peramban terasa kaku, tidak memiliki efek getaran/ripple sentuhan, dan tidak responsif seperti aplikasi mobile asli.

Kartu Berita Web Biasa

Konten teks standar tanpa animasi dan tanpa integrasi platform mobile.

2. IONIC FRAMEWORK (MOBILE UI)

Kenyamanan Smartphone Asli

Ionic menyediakan komponen UI siap pakai dengan efek sentuhan Material Design (Android) dan Cupertino (iOS) secara otomatis!

📲 Tombol Mobile Asli (ion-button) KARTU MOBILE CERDAS Portal MyUT Mobile Komponen beradaptasi otomatis di Android dan iOS dengan dukungan Dark Mode!
