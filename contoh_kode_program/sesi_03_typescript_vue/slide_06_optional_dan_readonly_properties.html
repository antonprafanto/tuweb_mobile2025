SLIDE 06 • MODUL 3 BMP UT

Properti Opsional (?) dan Mutlak Tidak-Dapat-Diubah (readonly)

Menjaga integritas data identitas mahasiswa agar tidak termutasi secara tidak sengaja.

🪪 Formulir Biodata Mahasiswa Terproteksi

🔒 Field ini diproteksi oleh TypeScript dengan kata kunci 'readonly'. NIM tidak boleh diubah setelah instansiasi!
Hasil Objek Data:
NIM: {{ mhs.nim }} | Nama: {{ mhs.nama }} | HP: {{ mhs.noHp || '(Belum Diisi)' }}

💡 Perbedaan Sintaks TypeScript:

interface ProfilMahasiswa {
  readonly nim: string;     // 🔒 Tidak bisa di-assign ulang: mhs.nim = '049' ❌ ERROR
  nama: string;             // 📝 Wajib ada nilai saat inisialisasi
  noHp?: string;            // ❓ Opsional: boleh undefined
  emailKampus?: string;     // ❓ Opsional
}
