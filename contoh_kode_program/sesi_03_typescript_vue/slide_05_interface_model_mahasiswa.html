Kontrak Data Resmi: Interface Model Mahasiswa & Mata Kuliah

Membangun cetak biru data akademik terstruktur yang digunakan pada Tugas Tutorial 1.

📘 PANDUAN PRAKTIKUM MAHASISWA

🛠️ Alat yang Digunakan: Google Chrome / Peramban Web Modern, VS Code (Berkas sumber: slide_05_interface_model_mahasiswa.ts).

🎯 Cara Menguji Interaksi: Isilah formulir mata kuliah di bawah (Kode, Nama, SKS, dan Nilai Huruf). Klik tombol "Validasi Sesuai Interface MataKuliah". Perhatikan bagaimana objek JavaScript yang terbentuk dipastikan sesuai dengan kontrak model TypeScript.

💡 Apa yang Terjadi di Balik Layar: Di TypeScript, kata kunci interface adalah kontrak murni waktu kompilasi (*type erasure*). Interface tidak menghasilkan baris JavaScript saat dibuild (*zero runtime overhead*), namun menjamin setiap komponen antarmuka yang membaca data mata kuliah tidak akan mengalami error salah nama properti.

export type NilaiHuruf = 'A' | 'B' | 'C' | 'D' | 'E';

export interface MataKuliah {
  readonly id: string;
  kode: string;
  nama: string;
  sks: number;
  nilaiHuruf?: NilaiHuruf;
}

export interface MahasiswaUT {
  readonly nim: string;
  nama: string;
  programStudi: string;
  daftarNilai: MataKuliah[];
}
