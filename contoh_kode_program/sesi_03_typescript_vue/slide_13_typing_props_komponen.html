SLIDE 13 • MODUL 3 BMP UT

Deklarasi Props Bertipe: defineProps<T>()

Memanfaatkan generic interface untuk memvalidasi props komponen anak secara ketat.

📘 PANDUAN PRAKTIKUM MAHASISWA

🛠️ Alat yang Digunakan: Google Chrome / Peramban Web Modern.

🎯 Cara Menguji Interaksi: Perhatikan kartu sub-komponen anak <kartu-mk> di bawah yang menerima objek props dari induk. Komponen anak merender kode, nama, SKS, dan nilai huruf secara rapi.

💡 Apa yang Terjadi di Balik Layar: Di Vue 3 TypeScript, kita tidak perlu menulis objek validasi runtime panjang seperti props: { mk: { type: Object, required: true } }. Cukup tulis defineProps<{ mk: MataKuliah }>(). Kompiler Vue akan otomatis mengonversi deklarasi tipe ini menjadi validasi props yang super efisien.

📐 Aliran Data Props Down dengan Pemeriksaan Tipe Kompiler Makro

📦 Komponen Anak: KartuMataKuliah

Data mata kuliah dikirim dari induk ke anak dengan jaminan tipe data interface:

💡 Kode TypeScript SFC:

// DI DALAM KOMPONEN ANAK (KartuMataKuliah.vue)
<script setup lang="ts">
// Deklarasi props murni berbasis tipe TypeScript (Type-based declaration)
const props = defineProps<{
  mk: {
    kode: string;
    nama: string;
    sks: number;
    nilaiHuruf?: string;
  };
  isUjianSelesai?: boolean; // Opsional
}>();
</script>
