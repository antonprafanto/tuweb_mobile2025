SLIDE 13 • MODUL 3 BMP UT

Deklarasi Props Bertipe: defineProps<T>()

Memanfaatkan generic interface untuk memvalidasi props komponen anak secara ketat.

📦 Komponen Anak: KartuMataKuliah

Data mata kuliah dikirim dari induk ke anak dengan jaminan tipe data interface:

💡 Kode TypeScript SFC:

// DI DALAM KOMPONEN ANAK (KartuMataKuliah.vue)
<script setup lang="ts">
// Deklarasi props murni berbasis tipe TypeScript (Type-based declaration)
const props = defineProps<{
  mk: {
    kode: string;
    nama: string;
    sks: number;
    nilaiHuruf?: string;
  };
  isUjianSelesai?: boolean; // Opsional
}>();
</script>
