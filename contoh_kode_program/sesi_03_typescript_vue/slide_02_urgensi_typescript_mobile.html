Urgensi TypeScript: Mencegah Crash Fatal Runtime pada Aplikasi Mobile

Membandingkan kelemahan silent failure JavaScript murni vs perlindungan compile-time TypeScript.

📘 PANDUAN PRAKTIKUM MAHASISWA

🛠️ Alat yang Digunakan: Google Chrome / Peramban Web Modern, DevTools Console (Tekan F12).

🎯 Cara Menguji Interaksi: 1. Klik tombol merah "💥 Simulasikan Error JavaScript" di panel kiri. Perhatikan bagaimana nilai bobot berubah menjadi NaN tanpa ada tanda error sama sekali sebelum fungsi dipanggil (*silent failure*).
2. Klik tombol hijau "🛡️ Periksa Proteksi TypeScript" di panel kanan untuk memahami cara kerja pencegahan typo sejak tahap penulisan kode di VS Code.

💡 Apa yang Terjadi di Balik Layar: JavaScript murni bersifat bertipe dinamis (*loosely typed*). Ketika Anda salah mengetik mhs.ipkSmt padahal aslinya mhs.ipk, JavaScript mengembalikan nilai undefined. Operasi aritmatika undefined * 25 menghasilkan NaN yang merusak total IPK mahasiswa. TypeScript Interface mencegah bencana ini secara instan saat waktu kompilasi (*compile-time error*).

📐 Perbandingan Alur Eksekusi: JavaScript Dinamis vs TypeScript Type Guard

📚 Referensi Modul: BMP UT STSI4303 Modul 3: "Sistem Tipe Data Statis TypeScript" • Microsoft TypeScript Handbook v5.x: "Why TypeScript Matters in Enterprise Mobile Apps".
1. JAVASCRIPT MURNI (DYNAMIC TYPING)

⚠️ Bencana Typo & Silent Failure

Ketika kita memanggil properti yang salah ketik (misal: mhs.ipkSemester tertulis mhs.ipkSmt), JavaScript tidak akan komplain saat ngoding. Tetapi saat kalkulasi, aplikasi menghasilkan nilai NaN!

Nama: {{ mhsJS.nama }}
Hasil Hitung Bobot: {{ hasilJS }}
// JavaScript Murni:
const mhs = { nama: 'Rani', ipk: 3.8 };

// Typo properti: mhs.skorIpk (tidak ada!)
const hasil = mhs.skorIpk * 25; 
// undefined * 25 = NaN (Aplikasi Rusak!)
2. TYPESCRIPT (STATIC TYPE CHECKING)

🛡️ Kontrak Data Mutlak (Interface)

TypeScript memaksa pengembang mendeklarasikan bentuk data (kontrak). Jika ada salah ketik 1 huruf saja, editor langsung memblokir kompilasi sebelum kode sempat dikirim ke smartphone!

Status Proteksi: ✅ Aktif (VS Code Intellisense)
Status Build: 0 Runtime Error Terdeteksi
// TypeScript Interface:
interface Mahasiswa {
  nama: string;
  ipk: number;
}

const mhs: Mahasiswa = { nama: 'Rani', ipk: 3.8 };

// ❌ COMPILE-TIME ERROR:
// Property 'skorIpk' does not exist on type 'Mahasiswa'!
console.log(mhs.skorIpk);
