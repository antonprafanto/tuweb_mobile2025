Mengelola Array Koleksi Bertipe: ref<MataKuliah[]>([])

Memastikan setiap operasi push, splice, dan filter selalu aman terhadap tipe data objek.

📋 Daftar Mata Kuliah: ref<MataKuliah[]>

{{ mk.kode }} - {{ mk.nama }} ({{ mk.sks }} SKS)

💡 Kode Mutasi Koleksi Bertipe:

// Deklarasi array bertipe:
const daftarMk = ref<MataKuliah[]>([
  { id: '1', kode: 'STSI4303', nama: 'Pemrograman Bergerak', sks: 3 }
]);

// Fungsi tambah dengan parameter bertipe mutlak:
const tambahMataKuliah = (item: MataKuliah): void => {
  daftarMk.value.push(item); // Aman dari salah tipe data!
};
