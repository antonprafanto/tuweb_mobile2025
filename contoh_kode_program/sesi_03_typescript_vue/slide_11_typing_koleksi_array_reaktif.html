Mengelola Array Koleksi Bertipe: ref<MataKuliah[]>([])

Memastikan setiap operasi push, splice, dan filter selalu aman terhadap tipe data objek.

📘 PANDUAN PRAKTIKUM MAHASISWA

🛠️ Alat yang Digunakan: Google Chrome / Peramban Web Modern.

🎯 Cara Menguji Interaksi: Klik tombol hijau "+ Tambah Mata Kuliah Terstruktur" untuk menyuntikkan data baru ke array. Kemudian klik tombol merah "✕ Hapus" pada salah satu baris. Perhatikan mutasi reaktif berjalan mulus dan struktur objek selalu terikat interface MataKuliah.

💡 Apa yang Terjadi di Balik Layar: Dalam pengerjaan Tugas 1, kita akan menambahkan dan menghapus mata kuliah. Dengan deklarasi const daftarMk = ref<MataKuliah[]>([]), compiler TypeScript akan mencegah kita memasukkan objek cacat yang tidak memiliki properti kode atau sks.

📐 Mutasi Array Koleksi Bertipe: Operasi push() & filter() Terproteksi

📋 Daftar Mata Kuliah: ref<MataKuliah[]>

{{ mk.kode }} - {{ mk.nama }} ({{ mk.sks }} SKS)

💡 Kode Mutasi Koleksi Bertipe:

// Deklarasi array bertipe:
const daftarMk = ref<MataKuliah[]>([
  { id: '1', kode: 'STSI4303', nama: 'Pemrograman Bergerak', sks: 3 }
]);

// Tambah data (Type Checking ketat):
const tambah = (item: MataKuliah): void => {
  daftarMk.value.push(item);
};

// Hapus data secara aman:
const hapus = (id: string): void => {
  daftarMk.value = daftarMk.value.filter(mk => mk.id !== id);
};
