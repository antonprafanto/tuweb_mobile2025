Deklarasi Typing Reaktif: ref<T> vs reactive<T>

Memanfaatkan TypeScript Generics untuk mengunci tipe data pada state reaktif Vue.

📘 PANDUAN PRAKTIKUM MAHASISWA

🛠️ Alat yang Digunakan: Google Chrome / Peramban Web Modern.

🎯 Cara Menguji Interaksi: Klik tombol "Tingkatkan Target (+0.05)" atau "Turunkan (-0.05)". Perhatikan bagaimana nilai target IPK termutasi dengan batas maksimum 4.00 dan terikat pada tipe data number.

💡 Apa yang Terjadi di Balik Layar: Di Vue 3 TypeScript, kurung sudut generik seperti ref<number>(3.75) memberi tahu kompiler bahwa properti .value hanya boleh diisi angka. Jika data awalnya kosong sebelum mengambil dari API, gunakan Union Type: ref<MahasiswaUT | null>(null)!

📐 Generics Wrapper: ref<T> Membungkus Nilai Reaktif dengan Tameng Tipe

💡 Sintaks TypeScript Generics pada ref & reactive:

// 1. Typing eksplisit pada ref primitif:
const targetIpk = ref<number>(3.75);

// 2. Typing union type saat state bisa bernilai null (misal sebelum fetch):
const dataUser = ref<MahasiswaUT | null>(null);

// 3. Typing pada reactive object:
const profil = reactive<MahasiswaUT>({
  nim: '043123456',
  nama: 'Dewi Lestari',
  upbjj: 'Jakarta',
  programStudi: 'Sistem Informasi',
  status: 'Aktif'
});
