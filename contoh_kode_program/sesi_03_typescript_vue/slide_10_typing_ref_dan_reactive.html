Deklarasi Typing Reaktif: ref<T> vs reactive<T>

Memanfaatkan Generics TypeScript untuk mengunci tipe data pada state Vue 3.

📱 Demonstrasi State Reaktif Bertipe

Profil Mahasiswa:

NIM: {{ profil.nim }}

Nama: {{ profil.nama }}

Target IPK: {{ targetIpk.toFixed(2) }}

💡 Sintaks TypeScript Generics pada ref & reactive:

// 1. Typing eksplisit pada ref primitif:
const targetIpk = ref<number>(3.75);

// 2. Typing union type saat state bisa bernilai null (misal sebelum fetch):
const dataUser = ref<MahasiswaUT | null>(null);

// 3. Typing pada reactive object:
const profil = reactive<MahasiswaUT>({
  nim: '043123456',
  nama: 'Dewi Lestari',
  upbjj: 'Jakarta',
  programStudi: 'Sistem Informasi',
  semesterBerjalan: 5,
  status: 'Aktif',
  daftarNilai: []
});
