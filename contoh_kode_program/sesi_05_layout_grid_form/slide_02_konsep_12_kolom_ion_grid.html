Fondasi Tata Letak: Sistem 12-Kolom Ionic Grid

Membedah wadah pembagi layar <ion-grid>, baris <ion-row>, dan kolom <ion-col> berbasis CSS Flexbox.

📘 PANDUAN PRAKTIKUM & EKSPLORASI MANDIRI
🛠️ Alat yang Digunakan: Google Chrome (cukup klik ganda berkas HTML ini), Konsol Pengembang (F12), Mode Ponsel (Ctrl + Shift + M).
🎯 Cara Menguji Interaksi: Perhatikan kartu visualisasi di sebelah kiri. Cobalah lakukan *Inspect Element* (klik kanan pada kotak kuning size="12" atau kotak biru size="6" $\rightarrow$ pilih Inspect). Anda akan melihat properti flex: 0 0 50% yang diterapkan secara otomatis oleh Ionic!
💡 Apa yang Terjadi di Balik Layar: Di balik elemen kustom <ion-grid>, Ionic mengimplementasikan spesifikasi W3C CSS Flexible Box Layout (Flexbox). Total 1 baris selalu bernilai 12 unit, sehingga pembagian kolom selalu presisi tanpa kalkulasi persentase manual.

🧩 3 Elemen Pembentuk Grid

Komponen Peran dalam Layout
<ion-grid> Kontainer terluar pengatur padding dan pembatas lebar.
<ion-row> Wadah baris horizontal flexbox pembungkus kolom.
<ion-col> Sel penampung isi konten dengan atribut ukuran size="1..12".

💻 Pola Kode Standar

<ion-grid>
  <!-- Baris 1: Formulir Dua Kolom Sejajar -->
  <ion-row>
    <ion-col size="6">
      <ion-input label="Nama Depan"></ion-input>
    </ion-col>
    <ion-col size="6">
      <ion-input label="Nama Belakang"></ion-input>
    </ion-col>
  </ion-row>
</ion-grid>
💡 Aturan Otomatis: Jika total nilai size dalam satu ion-row melebihi 12, kolom sisanya akan otomatis turun (*wrap*) rapi ke baris berikutnya.
