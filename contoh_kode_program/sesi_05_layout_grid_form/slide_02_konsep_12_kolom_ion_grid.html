Fondasi Tata Letak: Sistem 12-Kolom Ionic Grid

Membedah wadah pembagi layar <ion-grid>, baris <ion-row>, dan kolom <ion-col> berbasis CSS Flexbox.

📱 Visualisasi Pembagian 12 Kolom

Total lebar satu baris selalu berjumlah 12 unit kolom:

Baris 1: 1 Kolom Penuh (size="12" = 100%)
size="12" (Lebar Penuh)
Baris 2: Bagi Dua Seimbang (size="6" + size="6" = 50% / 50%)
size="6" (Kiri)
size="6" (Kanan)
Baris 3: Tiga Kolom (size="4" x 3 = 33.3% tiap kolom)
size="4"
size="4"
size="4"
Baris 4: Asimetris (size="8" Konten + size="4" Sidebar)
size="8" (Data Mahasiswa)
size="4" (Foto)

🧩 3 Elemen Pembentuk Grid

Komponen Peran dalam Layout
<ion-grid> Kontainer terluar pengatur padding dan pembatas lebar.
<ion-row> Wadah baris horizontal flexbox pembungkus kolom.
<ion-col> Sel penampung isi konten dengan atribut ukuran size="1..12".

💻 Pola Kode Standar

<ion-grid>
  <!-- Baris 1: Formulir Dua Kolom Sejajar -->
  <ion-row>
    <ion-col size="6">
      <ion-input label="Nama Depan"></ion-input>
    </ion-col>
    <ion-col size="6">
      <ion-input label="Nama Belakang"></ion-input>
    </ion-col>
  </ion-row>
</ion-grid>
💡 Aturan Otomatis: Jika total nilai size dalam satu ion-row melebihi 12, kolom sisanya akan otomatis turun (*wrap*) rapi ke baris berikutnya.
