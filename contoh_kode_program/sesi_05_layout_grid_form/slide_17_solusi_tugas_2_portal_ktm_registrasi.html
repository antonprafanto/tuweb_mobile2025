📘 PANDUAN STUDI KASUS PRAKTIKUM MANDIRI
🛠️ Alat yang Digunakan: Google Chrome (cukup klik ganda berkas HTML ini), DevTools (F12), Mode Ponsel (Ctrl + Shift + M), Visual Studio Code.
🎯 Cara Menguji Interaksi 5 Fitur Kunci: 1. Uji Regex NIM: Ganti NIM menjadi 8 digit atau sisipkan huruf; amati border merah dan pesan galat instan.
2. Uji Regex Email: Ganti domain menjadi @gmail.com; amati penolakan domain non-institusi.
3. Uji Dark Mode: Klik ikon bulan/matahari di toolbar atas; seluruh aplikasi beralih tema gelap seketika.
4. Uji Modal Alert & Toast: Klik tombol "🚀 Terbitkan KTM Digital"; verifikasi dialog konfirmasi <ion-alert> muncul lalu setujui untuk melihat <ion-toast>.
5. KTM Digital Reaktif: Buka tab "💳 Kartu KTM Digital"; foto avatar dan identitas otomatis sinkron dengan data yang Anda ketik!
💡 Apa yang Terjadi di Balik Layar: Seluruh data formulir diikat secara dua arah (v-model) pada objek reaktif Vue 3. Tiga properti komputasi (isNimValid, isNamaValid, isEmailValid) mengawal keabsahan data secara matematis sebelum memicu overlay alert.
