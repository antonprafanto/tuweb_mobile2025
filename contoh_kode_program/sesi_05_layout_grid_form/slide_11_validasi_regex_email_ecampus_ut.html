🔍 Anatomi Formula Regex Surel Kampus

Pola: /^[a-zA-Z0-9._%+-]+@ecampus\.ut\.ac\.id$/

Segmen Pola Makna & Penjelasan
^[a-zA-Z0-9._%+-]+ Nama pengguna (username) boleh berupa huruf, angka, titik, minus. Minimal 1 karakter (+).
@ecampus Karakter '@' wajib diikuti kata spesifik 'ecampus'.
\.ut\.ac\.id$ Tanda titik wajib di-escape (\.) agar tidak dianggap sebagai wildcard sembarang karakter!

💻 Fungsi Validator TypeScript

// Definisi Pola Regex Resmi Email Kampus UT
const REGEX_EMAIL_UT = /^[a-zA-Z0-9._%+-]+@ecampus\.ut\.ac\.id$/;

export const validasiEmailUT = (email: string): boolean => {
  return REGEX_EMAIL_UT.test(email.trim().toLowerCase());
};
