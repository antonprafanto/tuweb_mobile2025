SLIDE 11 • MODUL 5 BMP UT (KRITERIA TUGAS 2)

Validasi Pola Regex: Domain Resmi @ecampus.ut.ac.id

Membedah regular expression untuk membatasi pendaftaran hanya bagi pemilik surel institusi Universitas Terbuka.

📘 PANDUAN PRAKTIKUM & EKSPLORASI MANDIRI
🛠️ Alat yang Digunakan: Google Chrome / Peramban Web Modern (cukup klik ganda berkas HTML ini), DevTools (F12).
🎯 Cara Menguji Interaksi: Klik salah satu tombol contoh skenario: "✅ Contoh Sah", "❌ Salah Domain (@gmail.com)", atau "❌ Salah Akhiran (.com)". Amati bagaimana pola regex menyaring domain dengan ketat dan memberikan alasan galat spesifik!
💡 Apa yang Terjadi di Balik Layar: Titik (.) dalam regex merupakan karakter spesial yang berarti "sembarang karakter". Oleh karena itu, kita wajib menyisipkan tanda garis miring terbalik (\.) yang disebut escaping agar mesin regex hanya mencocokkan karakter titik harfiah.

🔍 Anatomi Formula Regex Surel Kampus

Pola: /^[a-zA-Z0-9._%+-]+@ecampus\.ut\.ac\.id$/

Segmen Pola Makna & Penjelasan
^[a-zA-Z0-9._%+-]+ Nama pengguna (username) boleh berupa huruf, angka, titik, minus. Minimal 1 karakter (+).
@ecampus Karakter '@' wajib diikuti kata spesifik 'ecampus'.
\.ut\.ac\.id$ Tanda titik wajib di-escape (\.) agar tidak dianggap sebagai wildcard sembarang karakter!

💻 Fungsi Validator TypeScript

// Definisi Pola Regex Resmi Email Kampus UT
const REGEX_EMAIL_UT = /^[a-zA-Z0-9._%+-]+@ecampus\.ut\.ac\.id$/;

export const validasiEmailUT = (email: string): boolean => {
  return REGEX_EMAIL_UT.test(email.trim().toLowerCase());
};
