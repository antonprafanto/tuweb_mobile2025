SLIDE 03 • MODUL 5 BMP UT

Tata Letak Responsif: Titik Henti Breakpoints Grid

Menyesuaikan tampilan kolom saat aplikasi dibuka di ponsel layar kecil (portrait), ponsel landscape, maupun tablet iPad.

📘 PANDUAN PRAKTIKUM & EKSPLORASI MANDIRI
🛠️ Alat yang Digunakan: Google Chrome (klik ganda berkas HTML ini), DevTools (F12), Mode Ponsel (Ctrl + Shift + M).
🎯 Cara Menguji Interaksi: Klik tombol "📱 Ponsel Tegak (340px)" lalu klik "📟 Tablet / Landscape (600px)". Perhatikan bagaimana dua kotak data mahasiswa yang semula menumpuk ke bawah (1 kolom) langsung bertransformasi menjadi berdampingan (2 kolom) secara instan!
💡 Apa yang Terjadi di Balik Layar: Atribut size="12" size-md="6" memadukan CSS Media Query bawaan Ionic. Saat lebar layar $\ge 768\text{px}$ (atau saat container melebar pada simulator), aturan size-md secara otomatis menimpa aturan default size="12".

📏 Standar Titik Henti (Breakpoints) Ionic

Breakpoint Ukuran Layar Target Perangkat
size (default) > 0px Smartphone Tegak (Portrait)
size-sm ≥ 576px Ponsel Layar Besar / Lipat
size-md ≥ 768px Tablet iPad / Ponsel Landscape
size-lg ≥ 992px Layar Laptop Desktop
