Validasi Pola Regex: Penegakan Format 9 Digit NIM UT

Membedah sintaks ekspresi reguler /^[0-9]{9}$/ untuk menjamin integritas Nomor Induk Mahasiswa Universitas Terbuka.

📘 PANDUAN PRAKTIKUM & EKSPLORASI MANDIRI
🛠️ Alat yang Digunakan: Google Chrome / Peramban Modern (cukup klik ganda berkas HTML ini), DevTools (F12).
🎯 Cara Menguji Interaksi: Klik 3 tombol uji cepat: "Isi Contoh Sah (9 Digit)", "Isi Kurang (6 Digit)", atau "Isi Huruf (Ada 'A')". Perhatikan bagaimana kotak umpan balik langsung bereaksi hijau (Valid) atau merah (Galat) secara real-time!
💡 Apa yang Terjadi di Balik Layar: Pola /^[0-9]{9}$/.test(nim) mengevaluasi string masukan. Karakter ^ mengunci awal string, [0-9] hanya membolehkan digit angka 0-9, {9} mewajibkan tepat 9 pengulangan, dan $ mengunci akhir string.

🔍 Bedah Anatomi /^[0-9]{9}$/

Simbol Regex Makna & Peran
^ Anchor awal string (pemeriksaan dimulai dari huruf paling depan).
[0-9] Karakter yang diizinkan HANYA angka 0 sampai 9 (menolak huruf & spasi).
{9} Pengali kuantitas: Tepat wajib berjumlah PERSIS 9 karakter angka.
$ Anchor akhir string (memastikan tidak ada karakter tambahan di ujung).

💻 Fungsi Validator TypeScript

// Definisi Pola Regex Resmi NIM UT
const REGEX_NIM_UT = /^[0-9]{9}$/;

export const validasiNim = (nim: string): boolean => {
  return REGEX_NIM_UT.test(nim.trim());
};
