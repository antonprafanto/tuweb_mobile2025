Arsitektur Theming: CSS Variables & prefers-color-scheme

Membedah cara Ionic mengendalikan skema warna terang dan gelap melalui variabel global CSS berstandar Web Components.

🎨 3 Pilar Variabel CSS Inti Ionic

Komponen Ionic tidak menggunakan warna latar hardcoded, melainkan merujuk pada variabel CSS di bawah ini:

Variabel CSS Mode Terang (Light) Mode Gelap (Dark)
--ion-background-color #ffffff (Putih Bersih) #121212 (Abu Gelap OLED)
--ion-text-color #000000 (Hitam Pekat) #ffffff (Putih Terang)
--ion-card-background #ffffff #1e1e1e (Kartu Elevasi)
💡 Kenyamanan Mata Mahasiswa: Mengapa bukan hitam pekat (#000000) untuk latar gelap? Karena abu gelap (#121212) mengurangi kontras ekstrem yang menyebabkan ketegangan mata saat membaca modul ajar di malam hari!

💻 Berkas theme/variables.css

/* Otomatis Mengikuti Preferensi OS Smartphone */
@media (prefers-color-scheme: dark) {
  body {
    --ion-background-color: #121212;
    --ion-text-color: #ffffff;
    --ion-card-background: #1e1e1e;
  }
}

/* Mengikuti Kelas Manual yang Dipicu Tombol Switch */
body.dark {
  --ion-background-color: #121212;
  --ion-text-color: #ffffff;
  --ion-card-background: #1e1e1e;
}

📱 Mengapa Mahasiswa Perlu Mendukung Keduanya?

Pengguna smartphone ada yang menyetel mode gelap otomatis sesuai waktu senja, namun banyak juga yang ingin mengubah mode secara manual melalui sakelar tombol di dalam aplikasi.
