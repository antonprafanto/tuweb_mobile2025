Konfirmasi Krusial: Kotak Dialog Modal <ion-alert>

Mencegah pengiriman data yang tidak sengaja tertekan melalui dialog verifikasi dua langkah (Two-Tier Confirmation).

📘 PANDUAN PRAKTIKUM & EKSPLORASI MANDIRI
🛠️ Alat yang Digunakan: Google Chrome / Peramban Web Modern (cukup klik ganda berkas HTML ini), DevTools (F12).
🎯 Cara Menguji Interaksi: Klik tombol biru "🚀 Kirim Berkas Pendaftaran Layanan". Layar akan terblokir oleh modal dialog ion-alert. Cobalah klik "Periksa Kembali" (batal), lalu coba klik tombol lagi dan pilih "Ya, Kirim Sekarang" untuk melihat callback konfirmasi dieksekusi!
💡 Apa yang Terjadi di Balik Layar: <ion-alert> bersifat modal-blocking (menolak interaksi pada background di bawah backdrop). Handler tombol role: 'confirm' mengembalikan Promise yang hanya merestui pengiriman data ke server jika pengguna mengklik 'Ya'.

🧩 Struktur Array Buttons ion-alert

Tombol dialog diatur melalui properti :buttons berupa array objek konfigurasi:

  • role: 'cancel': Menandai tombol pembatalan (posisi abu-abu netral).
  • handler: () => {}: Fungsi callback yang dieksekusi saat tombol diklik.
  • role: 'destructive': Memberikan penanda warna merah khusus untuk aksi penghapusan.

💻 Pola Kode Konfirmasi

const alertButtons = [
  {
    text: 'Periksa Kembali',
    role: 'cancel',
    handler: () => { console.log('Batal kirim'); }
  },
  {
    text: 'Ya, Kirim Sekarang',
    role: 'confirm',
    handler: () => {
      // Eksekusi pengiriman ke backend
      submitDataPendaftaran();
    }
  }
];
