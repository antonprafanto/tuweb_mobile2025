🚀 4 Pilar Pembelajaran Sesi 06 Mendatang

1. Arsitektur Capacitor Runtime Bridge

Memahami cara Capacitor bertindak sebagai 'jembatan' komunikasi antara JavaScript Webview dengan API native sistem operasi Android & iOS.

2. Bedah Struktur Folder android/ & Gradle

Membuka proyek di Android Studio, memahami build.gradle, SDK versions (Compile SDK, Target SDK, Min SDK), dan konfigurasi aset ikon aplikasi.

3. AndroidManifest.xml & Runtime Permissions

Tata kelola hak akses aplikasi smartphone: Izin akses kamera, penyimpanan memori, konektivitas internet, dan proteksi privasi pengguna.

4. Pengujian di Ponsel Fisik via scrcpy (Hemat RAM)

Solusi bagi mahasiswa bertopologi RAM 4–8GB: Menjalankan aplikasi langsung di smartphone Android pribadi lewat USB Debugging & mirroring layar tanpa beban emulator berat.
