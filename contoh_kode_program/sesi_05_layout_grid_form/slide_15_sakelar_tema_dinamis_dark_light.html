💾 Status tema tersimpan otomatis di: localStorage.getItem('theme_ut')

💻 Logika Reaktif Pengubah Tema

const isDark = ref(false);

const toggleTheme = (ev: CustomEvent) => {
  isDark.value = ev.detail.checked;
  
  // 1. Tambah/Hapus Kelas pada Dokumen HTML
  document.body.classList.toggle('dark', isDark.value);
  
  // 2. Simpan Preferensi agar tidak hilang saat refresh
  localStorage.setItem('theme_ut', isDark.value ? 'dark' : 'light');
};

// 3. Pulihkan Tema Tersimpan saat Aplikasi Dibuka
onMounted(() => {
  const saved = localStorage.getItem('theme_ut');
  if (saved === 'dark') {
    isDark.value = true;
    document.body.classList.add('dark');
  }
});
💡 Kriteria Penilaian Tugas 2: Penguji akan menguji fitur toggle ini untuk memastikan seluruh elemen (kartu, teks, tombol) berganti warna secara proporsional dan nyaman dipandang!
