Peralihan Tema Real-Time: Sakelar Dark & Light Mode

Mengintegrasikan tombol ion-toggle dengan manipulasi kelas body dan penyimpanan persistensi LocalStorage.

📘 PANDUAN PRAKTIKUM & EKSPLORASI MANDIRI
🛠️ Alat yang Digunakan: Google Chrome / Peramban Web Modern (cukup klik ganda berkas HTML ini), DevTools (F12).
🎯 Cara Menguji Interaksi: Geser tombol <ion-toggle> di panel simulasi ponsel. Seluruh tampilan aplikasi akan langsung bertransformasi mulus menjadi tema gelap! Muat ulang halaman (tekan F5); Anda akan melihat preferensi tema Anda tetap tersimpan berkat localStorage!
💡 Apa yang Terjadi di Balik Layar: Event @ionChange memicu fungsi toggleTheme yang melakukan dua hal: menyuntikkan kelas .dark-mode pada elemen akar antarmuka dan menyimpan string 'dark' atau 'light' ke Web Storage browser.

💾 Status tema tersimpan otomatis di: localStorage.getItem('theme_ut')

💻 Logika Reaktif Pengubah Tema

const isDark = ref(false);

const toggleTheme = (ev) => {
  isDark.value = ev.detail.checked;
  
  // 1. Simpan Preferensi ke LocalStorage
  localStorage.setItem('theme_ut', isDark.value ? 'dark' : 'light');
};

// 2. Pulihkan Tema Tersimpan saat Aplikasi Dibuka
onMounted(() => {
  const saved = localStorage.getItem('theme_ut');
  if (saved === 'dark') {
    isDark.value = true;
  }
});
