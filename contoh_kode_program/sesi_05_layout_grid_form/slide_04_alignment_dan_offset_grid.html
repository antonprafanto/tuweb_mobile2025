Presisi Tata Letak: Perataan (Alignment) & Offset Kolom

Mengatur perataan vertikal/horizontal dan pergeseran kolom (offset) untuk memusatkan kartu formulir login atau profil.

📘 PANDUAN PRAKTIKUM & EKSPLORASI MANDIRI
🛠️ Alat yang Digunakan: Google Chrome / Peramban Modern, Visual Studio Code.
🎯 Cara Menguji Interaksi: Klik 3 tombol konfigurasi di panel playground: "1. Offset Center", "2. Justify Between", dan "3. Align Items Center". Amati bagaimana posisi kotak kartu berubah secara visual di dalam canvas.
💡 Apa yang Terjadi di Balik Layar: Atribut offset="2" menerapkan margin-left: 16.666% (2/12 bagian) pada elemen <ion-col>, sementara kelas ion-align-items-center menerapkan align-items: center pada flex container <ion-row>.

💡 Rumus Centering: offset = (12 - size) / 2. Contoh: Kartu selebar 8 unit dipusatkan dengan offset="2" ((12 - 8) / 2 = 2).

🧩 Kelas Utilitas Flexbox Resmi

Ionic menyertakan utility class CSS bawaan yang siap disematkan pada tag <ion-row>:

  • class="ion-justify-content-center": Menengahkan kolom secara horizontal.
  • class="ion-justify-content-between": Memisahkan elemen ke ujung kiri dan ujung kanan secara seimbang.
  • class="ion-align-items-center": Menyamakan titik tengah vertikal meski tinggi isi kolom berbeda.
  • offset="N": Menggeser kolom sebanyak N unit ke kanan.

💻 Cuplikan Template

        </ion-card-content>

    </ion-col>
  </ion-row>
</ion-grid>
