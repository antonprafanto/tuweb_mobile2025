Kontrol Masukan Modern: Komponen <ion-input>

Memanfaatkan floating label, tombol hapus cepat (clear-button), tipe masukan khusus, dan pemilihan keyboard virtual smartphone.

📘 PANDUAN PRAKTIKUM & EKSPLORASI MANDIRI
🛠️ Alat yang Digunakan: Google Chrome (klik ganda berkas HTML ini), DevTools (F12), Mode Ponsel (Ctrl + Shift + M).
🎯 Cara Menguji Interaksi: Klik pada kolom "Nomor Induk Mahasiswa (NIM)". Perhatikan label melayang ke atas (*floating label*). Ketik angka NIM Anda, lalu amati munculnya ikon silang (X) di sebelah kanan untuk menghapus teks dengan sekali klik (*clear-input*). Amati pula panel data reaktif di bawah form yang terisi secara instan!
💡 Apa yang Terjadi di Balik Layar: Komponen <ion-input> membungkus elemen native <input> di dalam Web Components Shadow DOM. Atribut inputmode="numeric" mengirimkan instruksi ke sistem operasi Android/iOS untuk langsung mengaktifkan layout numeric keypad.

🧩 Fitur Unggulan ion-input

  • label-placement="floating": Label melayang anggun ke atas saat kolom input difokuskan.
  • fill="outline" | "solid": Tampilan berbingkai tegas atau latar kotak abu-abu.
  • :clear-input="true": Memunculkan ikon silang (X) otomatis di kanan untuk menghapus teks dengan sekali tap jempol.
  • inputmode="numeric": Memerintahkan ponsel memunculkan papan ketik angka (*numeric keypad*) alih-alih keyboard alfabet biasa.

💻 Pola Kode Modern Ionic 7/8

<ion-input
  label="NIM Mahasiswa"
  label-placement="floating"
  fill="outline"
  inputmode="numeric"
  :clear-input="true"
  v-model="nim"
  helper-text="Masukkan 9 digit angka">
</ion-input>
