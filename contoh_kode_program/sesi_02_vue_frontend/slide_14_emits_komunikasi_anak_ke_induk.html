Komunikasi Komponen Anak ke Induk: Custom Events via emit()

Filosofi: "Props Down, Events Up". Anak mengirim sinyal saat terjadi interaksi pengguna.

📖 Panduan Praktikum Mandiri Mahasiswa (Pemula & Awam)

  1. 🛠️ Alat yang Digunakan: Buka berkas HTML ini di Google Chrome. Gunakan Developer Tools (F12) untuk mengamati jalannya aplikasi.
  2. 🎯 Cara Menguji Interaksi:
    • Klik tombol + atau - pada salah satu modul BMP untuk menambah/mengurangi kuantitas.
    • Klik tombol 🗑️ untuk menghapus modul dari keranjang belanja.
    • Perhatikan kotak hijau TOTAL PEMBAYARAN yang seketika berubah otomatis tanpa perlu me-reload halaman!
  3. 💡 Apa yang Terjadi di Balik Layar (Filosofi "Events Up"): Komponen anak (modul-item) tidak memiliki wewenang untuk mengubah atau menghapus data keranjang milik induk secara langsung. Anak hanya bertindak memancarkan sinyal event ($emit('tambah-qty', modul.id)). Komponen induk menangkap sinyal ini lewat pendengar event kustom (@tambah-qty="handleTambahQty"), lalu mengubah state miliknya sendiri secara aman!

💡 Pola Props Down & Events Up:

// 1. DI KOMPONEN ANAK: Pancarkan event ke induk
setup(props, { emit }) {
  const kirimSinyalHapus = () => {
    emit('hapus-item', props.modul.id); // Payload ID
  };
}

// 2. DI KOMPONEN INDUK: Dengarkan dengan @nama-event
<modul-item @hapus-item="handleHapusItem" />
