Komunikasi Komponen Anak ke Induk: Custom Events via emit()

Filosofi: "Props Down, Events Up". Anak mengirim sinyal saat terjadi interaksi pengguna.

🛒 Pemesanan Buku Materi Pokok (BMP) UT Online

Komponen anak tidak boleh mengubah data induk secara langsung. Komponen anak memancarkan event emit ke induk:

Keranjang pesanan modul kosong.
TOTAL PEMBAYARAN: Rp {{ totalBayar.toLocaleString('id-ID') }}

💡 Pola Props Down & Events Up:

// 1. DI KOMPONEN ANAK: Pancarkan event ke induk
setup(props, { emit }) {
  const kirimSinyalHapus = () => {
    emit('hapus-item', props.modul.id); // Payload ID
  };
}

// 2. DI KOMPONEN INDUK: Dengarkan dengan @nama-event
<modul-item @hapus-item="handleHapusItem" />
