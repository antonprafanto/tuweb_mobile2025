List Rendering (v-for) & Urgensi Atribut :key Unik

Merender koleksi data array serta mencegah bug rendering Virtual DOM dengan key identitas.

💡 Panduan Ramah Pemula:
• Alat yang Digunakan: Buka berkas ini di Google Chrome (klik ganda berkas HTML).
• Uji Mode Mobile: Tekan F12 lalu Ctrl + Shift + M untuk mengamati daftar list dalam kartu smartphone.
• Eksperimen Interaktif: Coba tambahkan mata kuliah baru atau klik tombol Hapus pada salah satu mata kuliah. Berkat atribut :key="mk.id", Vue menghapus elemen yang tepat tanpa merusak urutan daftar lainnya!

💡 Mengapa :key Sangat Penting di Vue 3?

<!-- CONTOH SALAH: Menggunakan index sebagai key -->
<li v-for="(item, index) in list" :key="index">...</li>

<!-- CONTOH BENAR: Menggunakan ID Unik dari database/model -->
<li v-for="mk in daftarMk" :key="mk.id">
  {{ mk.nama }}
</li>
💡 Penjelasan Algoritma Diffing: Ketika sebuah baris dihapus, Vue membandingkan Virtual DOM berdasarkan :key. Jika kita hanya memakai index, baris di bawahnya akan bergeser dan mengambil alih index lama, sehingga komponen anak yang memiliki state internal (seperti input formulir) dapat tertukar datanya!
