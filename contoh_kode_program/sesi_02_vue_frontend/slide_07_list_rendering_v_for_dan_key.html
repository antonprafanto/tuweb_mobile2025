💡 Mengapa :key Sangat Penting di Vue 3?

<!-- CONTOH SALAH: Menggunakan index sebagai key -->
<li v-for="(item, index) in list" :key="index">...</li>

<!-- CONTOH BENAR: Menggunakan ID Unik dari database/model -->
<li v-for="mk in daftarMk" :key="mk.id">
  {{ mk.nama }}
</li>
💡 Penjelasan Algoritma Diffing: Ketika sebuah baris dihapus, Vue membandingkan Virtual DOM berdasarkan :key. Jika kita hanya memakai index, baris di bawahnya akan bergeser dan mengambil alih index lama, sehingga komponen anak yang memiliki state internal (seperti input formulir) dapat tertukar datanya!
