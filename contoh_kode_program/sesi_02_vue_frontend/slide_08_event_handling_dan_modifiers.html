Penanganan Event (@event) & Event Modifiers (.prevent, .stop)

Mengendalikan interaksi pengguna dan mencegah aksi bawaan browser tanpa kode rumit.

💡 Panduan Ramah Pemula:
• Alat yang Digunakan: Buka berkas ini di Google Chrome (klik ganda berkas HTML).
• Uji Mode Mobile: Tekan F12 lalu Ctrl + Shift + M untuk simulasi layar ponsel.
• Eksperimen Interaktif:
1. Tekan tombol Kirim Tanggapan Diskusi. Berkat @submit.prevent, browser TIDAK reload/kedip putih!
2. Klik tombol Beri Like di dalam kotak kuning. Berkat @click.stop, event klik ditahan dan tidak tembus ke kartu induk!
