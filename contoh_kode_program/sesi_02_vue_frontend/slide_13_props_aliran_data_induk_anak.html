Komunikasi Komponen: Aliran Data Satu Arah via Props (Parent → Child)

Komponen induk menyalurkan data ke komponen anak yang dapat digunakan berulang kali (*reusable*).

📖 Panduan Praktikum Mandiri Mahasiswa (Pemula & Awam)

  1. 🛠️ Alat yang Digunakan: Cukup gunakan Google Chrome untuk melihat hasil render. Buka Developer Tools (F12) > tab Console jika ingin bereksperimen.
  2. 🎯 Cara Menguji Interaksi:
    • Perhatikan ketiga kartu tutor di bawah. Seluruh kartu menggunakan satu cetak biru komponen anak yang sama (<kartu-tutor>).
    • Data spesifik seperti nama dosen, kode mata kuliah, kelas, dan nilai rating dikirimkan dari komponen induk (parent) melalui atribut khusus yang disebut props.
  3. 💡 Apa yang Terjadi di Balik Layar (Prinsip One-Way Data Flow): Data mengalir tegas hanya dari atas ke bawah (Props Down). Komponen anak bersifat pasif murni menerima masukan (read-only). Anak dilarang keras memodifikasi langsung nilai props (misal: props.rating = 5.0). Jika komponen anak ingin mengubah data, ia harus mengirim sinyal event ke induk melalui mekanisme emit (dibahas pada Slide 14)!

👨‍🏫 Komponen Induk: Daftar Tutor Pengampu Tuton FST UT

Data array di bawah ini berada di komponen induk dan dikirimkan ke sub-komponen menggunakan atribut :tutor="item":

💡 Aturan Emas Aliran Data Satu Arah (One-Way Data Flow):

// 1. Komponen Anak Mendefinisikan Props yang Diterima
const KartuTutor = {
  props: {
    nama: { type: String, required: true },
    mataKuliah: String,
    kelas: String,
    rating: Number
  },
  template: `...`
};

// 2. Komponen Induk Mengirimkan Nilai secara Dinamis
<kartu-tutor :nama="item.nama" :mata-kuliah="item.mk" />
🚫 Dilarang Keras: Komponen anak tidak boleh mengubah langsung nilai props (misal: props.rating = 5). Jika anak ingin mengubah data, ia wajib mengirimkan sinyal event ke induk melalui emit!
