Anatomi Single File Component (SFC .vue): Template, Script, & Style Scoped

Standar arsitektur industri merangkum struktur, perilaku, dan gaya dalam satu berkas modular.

📖 Panduan Praktikum Mandiri Mahasiswa (Pemula & Awam)

  1. 🛠️ Alat yang Digunakan: Buka berkas HTML ini langsung di Google Chrome atau peramban web modern Anda. Untuk proyek nyata, gunakan VS Code dengan ekstensi Vue - Official (Volar).
  2. 🎯 Cara Menguji Interaksi:
    • Klik tombol tab di panel kiri (📄 Lengkap, 1. <template>, 2. <script>, atau 3. <style scoped>) untuk membaca bedah anatomi tiap bagian.
    • Di panel kanan, klik tombol "🎓 Naik Semester" untuk membuktikan komponen memiliki state internal yang mandiri dan reaktif.
  3. 💡 Apa yang Terjadi di Balik Layar: Berkas .vue menyatukan tiga pilar rekayasa web (struktur, logika, gaya) ke dalam satu wadah modular. Compiler bundler (seperti Vite) membedah berkas ini saat proses build: <template> diubah menjadi Virtual DOM Render Function, <script setup> dieksekusi dalam konteks reaktif, dan <style scoped> diberi atribut identitas unik otomatis (misal: data-v-7a7a37b0) sehingga gayanya tidak akan pernah bocor merusak komponen lain!
