💡 Kapan Pakai ref() vs reactive()?

// 1. Gunakan ref() untuk nilai tunggal primitif
const skor = ref(100);

// 2. Gunakan reactive() untuk satu kesatuan objek
const mhs = reactive({
  nim: '043999888',
  nama: 'Budi Santoso',
  semester: 5
});
// Akses langsung tanpa .value!
mhs.semester++;
⚠️ Peringatan Penting: Jangan melakukan destructuring objek const { nama } = mhs karena reaktivitasnya akan terputus! Jika ingin destructuring, gunakan pembungkus toRefs(mhs).
