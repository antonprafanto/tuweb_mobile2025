Pengikatan Data Dua Arah (v-model) & Input Modifiers

Sinkronisasi otomatis antara input antarmuka pengguna dengan state JavaScript.

💡 Panduan Ramah Pemula:
• Alat yang Digunakan: Buka berkas ini di Google Chrome (klik ganda berkas HTML).
• Uji Mode Mobile: Tekan F12 lalu Ctrl + Shift + M untuk merasakan pengisian formulir di layar sentuh ponsel.
• Eksperimen Interaktif: Ubah teks nama, pilih dropdown prodi, atau centang fokus riset. Perhatikan bagaimana objek JSON di sebelah kanan terisi secara seketika tanpa perlu tombol simpan manual!

Referensi Akademik: BMP UT STSI4303 Modul 2 & Dokumentasi Resmi Vue.js 3: "Form Input Bindings (v-model)" (vuejs.org/guide/essentials/forms).

⚡ Live Reaktif State (Data Model JSON)

Ketik atau pilih opsi di sebelah kiri, objek state di bawah terbarui tanpa lag:

{{ JSON.stringify(form, null, 2) }}
💡 Tiga Modifiers Sakti v-model:
  • .trim : Otomatis menghapus spasi kosong di awal & akhir.
  • .number : Mengonversi string input menjadi angka numerik asli.
  • .lazy : Menunda sinkronisasi hingga event change (saat blur).
