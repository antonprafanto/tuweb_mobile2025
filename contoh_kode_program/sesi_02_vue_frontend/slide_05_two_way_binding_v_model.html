Pengikatan Data Dua Arah (v-model) & Input Modifiers

Sinkronisasi otomatis antara input antarmuka pengguna dengan state JavaScript.

⚡ Live Reaktif State (Data Model JSON)

Ketik atau pilih opsi di sebelah kiri, objek state di bawah terbarui tanpa lag:

{{ JSON.stringify(form, null, 2) }}
💡 Tiga Modifiers Sakti v-model:
  • .trim : Otomatis menghapus spasi kosong di awal & akhir.
  • .number : Mengonversi string input menjadi angka numerik asli.
  • .lazy : Menunda sinkronisasi hingga event change (saat blur).
