Sistem Reaktivitas Dasar: ref() dan Unboxing .value

Membungkus tipe data primitif (angka, string, boolean) menjadi objek reaktif.

💡 Panduan Ramah Pemula:
• Alat yang Digunakan: Buka berkas ini di Google Chrome (klik ganda dari File Explorer).
• Uji Mode Mobile: Tekan F12 lalu Ctrl + Shift + M untuk simulasi layar ponsel.
• Aturan Emas: Perhatikan tombol di bawah: ketika Anda mengklik tombol, di JavaScript kita memanipulasi totalSks.value += 3, namun di antarmuka HTML cukup ditulis {{ totalSks }} tanpa .value!

🔍 Aturan Emas ref() yang Wajib Diingat:

// 1. Di dalam JavaScript: WAJIB menggunakan .value
const totalSks = ref(18);
totalSks.value += 3; // Mengubah nilai

// 2. Di dalam Template HTML: TIDAK PERLU .value (Otomatis Di-unwrap!)
<p>Nilai SKS: {{ totalSks }}</p>
💡 Kenapa butuh .value? Karena JavaScript primitif (seperti angka dan boolean) di-pass by value. Vue membungkusnya dalam sebuah objek kontainer agar dapat memasang getter & setter untuk melacak kapan datanya diakses dan diubah!
