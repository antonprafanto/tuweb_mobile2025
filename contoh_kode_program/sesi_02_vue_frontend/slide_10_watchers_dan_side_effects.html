Pemantau Data (watch) & Efek Samping (Side Effects)

Mengeksekusi aksi asinkron seperti Auto-Save ke penyimpanan lokal saat data berubah.

• Alat yang Digunakan: Buka berkas ini di Google Chrome (klik ganda berkas HTML).
• Uji Mode Mobile: Tekan F12 lalu Ctrl + Shift + M untuk simulasi layar ponsel.
• Eksperimen Interaktif: Ketikkan catatan pada kolom di bawah. Perhatikan indikator berubah kuning (Mengetik...), lalu setelah jeda 500ms berubah hijau (Tersimpan ke Storage HP). Fitur ini menyelamatkan tugas Anda agar tidak hilang saat koneksi terputus!

💡 Perbedaan Inti: computed vs watch

// COMPUTED: Murni untuk menghitung nilai baru tanpa efek samping
const total = computed(() => harga.value * jumlah.value);

// WATCH: Untuk menjalankan side-effect (I/O, localStorage, HTTP Request)
watch([judul, isi], ([newJudul, newIsi], [oldJudul, oldIsi]) => {
  localStorage.setItem('draft_belajar_ut', JSON.stringify({
    judul: newJudul,
    isi: newIsi
  }));
});
