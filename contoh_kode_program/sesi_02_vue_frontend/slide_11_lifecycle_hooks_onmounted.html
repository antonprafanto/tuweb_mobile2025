Siklus Hidup Komponen: onMounted, onUpdated, & onUnmounted

Mengelola inisialisasi resource dan membersihkan memori (mencegah memory leak).

💡 Panduan Ramah Pemula:
• Alat yang Digunakan: Buka berkas ini di Google Chrome (klik ganda berkas HTML).
• Uji Mode Mobile: Tekan F12 lalu Ctrl + Shift + M untuk simulasi layar ponsel.
• Eksperimen Interaktif: Klik tombol Bongkar Komponen (Unmount Timer) dan amati log konsol hitam. Perhatikan bagaimana onUnmounted() otomatis mematikan interval waktu agar baterai ponsel tidak terkuras sia-sia!
