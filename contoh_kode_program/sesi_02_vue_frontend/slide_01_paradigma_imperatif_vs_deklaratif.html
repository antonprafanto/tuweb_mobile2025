Paradigma Pemrograman: Imperatif (Vanilla JS) vs Deklaratif (Vue.js 3)

Perhatikan perbedaan cara kerja: Pendekatan manual mencari elemen DOM vs Pendekatan reaktif berbasis state.

CARA IMPERATIF (VANILLA JAVASCRIPT)

Manipulasi DOM Manual

Pengembang harus mencari elemen dengan getElementById dan memerintahkan browser langkah demi langkah bagaimana memperbarui teksnya.

0
// 1. Inisialisasi variabel manual
let count = 0;
const display = document.getElementById('vanilla-counter');

// 2. Pasang event listener manual
document.getElementById('btn-vanilla-tambah')
  .addEventListener('click', () => {
    count++;
    // 3. Wajib manual perbarui teks DOM!
    display.textContent = count;
  });
⚠️ Kelemahan Imperatif: Jika ada 10 elemen yang bergantung pada count, Anda harus menulis 10 baris kode mutasi DOM secara manual. Rawan lupa dan rawan bug!
CARA DEKLARATIF (VUE.JS 3 REAKTIF)

Fokus pada Data (State-Driven UI)

Pengembang cukup mendefinisikan data reaktif (ref). Ketika data berubah, antarmuka otomatis memperbarui dirinya sendiri secara cerdas.

{{ count }}
// Menggunakan Vue 3 Composition API
const { createApp, ref } = Vue;

createApp({
  setup() {
    // Cukup ubah state, UI ikut otomatis!
    const count = ref(0);
    const tambah = () => count.value++;
    const reset = () => count.value = 0;

    return { count, tambah, reset };
  }
}).mount('#vue-app');
✅ Kelebihan Deklaratif: Tidak ada lagi getElementById atau innerHTML. Kode jauh lebih ringkas, aman, dan mudah diuji pada aplikasi mobile berskala besar!
