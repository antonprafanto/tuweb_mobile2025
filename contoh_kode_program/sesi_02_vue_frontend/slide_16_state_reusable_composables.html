State Management Ringan: Pola Custom Composables (useKRSManager)

Memisahkan logika bisnis dari tampilan antarmuka (UI) agar kode bersih, modular, dan teruji.

📖 Panduan Praktikum Mandiri Mahasiswa (Pemula & Awam)

  1. 🛠️ Alat yang Digunakan: Buka berkas HTML ini langsung di Google Chrome atau peramban web modern Anda.
  2. 🎯 Cara Menguji Interaksi:
    • Klik tombol + Ambil Mata Kuliah pada kartu mata kuliah yang tersedia.
    • Perhatikan indikator Total Beban SKS di bagian atas. Ketika mendekati atau mencapai 24 SKS, sistem otomatis mengunci penambahan mata kuliah baru (tombol menjadi nonaktif).
    • Klik tombol ✓ Terpilih (Klik Batalkan) untuk melepas mata kuliah dan membebaskan kuota SKS kembali.
  3. 💡 Apa yang Terjadi di Balik Layar (Filosofi Composables): Seluruh state (krs), kalkulasi logika (totalSks, isPenuh), dan fungsi manipulasi data (ambilMk, lepasMk) tidak ditaruh langsung di dalam elemen UI, melainkan diisolasi di dalam fungsi reusable bernama useKRSManager(). Hal ini sesuai dengan prinsip Clean Architecture: tampilan UI dapat berganti bentuk, tetapi logika bisnis inti KRS tetap utuh dan dapat diuji secara mandiri (unit testing)!

💡 Struktur Berkas Composable: useKRSManager.js

// Logika bisnis terisolasi 100% dari elemen DOM/HTML!
export function useKRSManager() {
  const krs = ref([]);
  const totalSks = computed(() => krs.value.reduce((sum, item) => sum + item.sks, 0));
  const isPenuh = computed(() => totalSks.value >= 24);

  const ambilMk = (mk) => {
    if (totalSks.value + mk.sks <= 24) krs.value.push(mk);
  };
  const lepasMk = (id) => {
    krs.value = krs.value.filter(item => item.id !== id);
  };

  return { krs, totalSks, isPenuh, ambilMk, lepasMk };
}
