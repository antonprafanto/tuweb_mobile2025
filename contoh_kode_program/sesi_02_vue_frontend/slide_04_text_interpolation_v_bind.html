Text Interpolation {{ }} & Pengikatan Atribut Dinamis (v-bind)

Mengikat nilai JavaScript ke dalam teks, atribut HTML, class CSS, dan inline style.

💡 Panduan Ramah Pemula:
• Alat yang Digunakan: Buka berkas ini di Google Chrome (klik ganda berkas HTML).
• Uji Mode Mobile: Tekan F12 lalu Ctrl + Shift + M untuk mengamati kartu tagihan dalam ukuran layar ponsel.
• Eksperimen Interaktif: Klik tombol Ubah Status Tagihan. Amati warna border berubah otomatis lewat :class dan tombol Cetak Kartu Ujian yang awalnya nonaktif (disabled) langsung aktif!

Sintaks Singkat (Shorthand):

<!-- Format Panjang: v-bind:class -->
<div v-bind:class="statusClass"></div>

<!-- Shorthand Resmi (Gunakan Ini!): :class -->
<div :class="['status-box', isLunas ? 'lunas' : 'belum-lunas']"></div>

<!-- Pengikatan Atribut Boolean (disabled, checked) -->
<button :disabled="!isLunas">Cetak KTPU</button>
