Mengapa Vue 3 Butuh TypeScript? Bahaya Bug Runtime vs Proteksi Interface

Melihat secara langsung bagaimana TypeScript menyelamatkan aplikasi mobile kita dari bug fatal undefined.

📖 Panduan Praktikum Mandiri Mahasiswa (Pemula & Awam)

  1. 🛠️ Alat yang Digunakan: Buka berkas HTML ini di Google Chrome untuk melihat demonstrasi. Untuk mempelajari TypeScript di Sesi 03 pekan depan, siapkan VS Code dengan ekstensi TypeScript and JavaScript Language Features serta Vue - Official.
  2. 🎯 Cara Menguji Interaksi:
    • Di panel kiri (JavaScript Murni), klik tombol merah "💥 Buktikan Typo JavaScript (Klik Di Sini)".
    • Amati apa yang terjadi: JavaScript tidak mengeluarkan peringatan apa pun sebelum dijalankan. Namun saat tombol diklik, nilai properti yang typo menghasilkan undefined dan hasil perkalian menjadi NaN (Not a Number)!
    • Di panel kanan (TypeScript + Vue 3), baca bagaimana interface Mahasiswa mencegah bug fatal tersebut sejak detik pertama Anda mengetik kode di editor.
  3. 💡 Apa yang Terjadi di Balik Layar (Perbedaan Paradigma): JavaScript bertipe dinamis (dynamic typing), artinya keabsahan tipe data baru diperiksa saat aplikasi dijalankan oleh pengguna di ponsel (runtime). Sebaliknya, TypeScript memberlakukan pemeriksaan statis (static type-checking) saat tahap kompilasi. Jika salah ketik satu huruf nama kolom, kode langsung ditolak kompilasi sehingga tidak ada bug typo yang sampai lolos ke pengguna!

⚠️ Bencana Typo Tanpa Peringatan

Di JavaScript, jika Anda salah ketik nama properti (misal: mhs.skorIpk padahal aslinya mhs.ipk), JavaScript tidak akan memberi tahu error saat ngoding, melainkan menghasilkan nilai undefined di HP pengguna!

Nama: {{ mhsJS.nama }}
IPK (Typo Akses Properti): {{ hasilKalkulasiJS }}
// JavaScript diam saja saat kita typo:
const hasil = mhs.skorIpk * 25; 
// undefined * 25 === NaN (Crash logika!)
TYPESCRIPT + VUE 3 (STATIC CONTRACT)

🛡️ Proteksi Kontrak Kuat (Interface)

Di Sesi 03 pekan depan, kita akan menerapkan TypeScript Interface. Jika salah ketik satu huruf saja, editor VS Code langsung memberi garis merah sebelum aplikasi sempat dijalankan! 

// Definisi Kontrak Data (Sesi 03)
interface Mahasiswa {
  nim: string;
  nama: string;
  ipk: number;
}

const mhs: Mahasiswa = {
  nim: '043123456',
  nama: 'Budi',
  ipk: 3.75
};

// ❌ ERROR SAAT KETIK:
// Property 'skorIpk' does not exist on type 'Mahasiswa'!
console.log(mhs.skorIpk);
