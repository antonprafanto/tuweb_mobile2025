JAVASCRIPT MURNI (DYNAMIC TYPING)

⚠️ Bencana Typo Tanpa Peringatan

Di JavaScript, jika Anda salah ketik nama properti (misal: mhs.skorIpk padahal aslinya mhs.ipk), JavaScript tidak akan memberi tahu error saat ngoding, melainkan menghasilkan nilai undefined di HP pengguna!

Nama: {{ mhsJS.nama }}
IPK (Typo Akses Properti): {{ hasilKalkulasiJS }}
// JavaScript diam saja saat kita typo:
const hasil = mhs.skorIpk * 25; 
// undefined * 25 === NaN (Crash logika!)
TYPESCRIPT + VUE 3 (STATIC CONTRACT)

🛡️ Proteksi Kontrak Kuat (Interface)

Di Sesi 03 pekan depan, kita akan menerapkan TypeScript Interface. Jika salah ketik satu huruf saja, editor VS Code langsung memberi garis merah sebelum aplikasi sempat dijalankan! 

// Definisi Kontrak Data (Sesi 03)
interface Mahasiswa {
  nim: string;
  nama: string;
  ipk: number;
}

const mhs: Mahasiswa = {
  nim: '043123456',
  nama: 'Budi',
  ipk: 3.75
};

// ❌ ERROR SAAT KETIK:
// Property 'skorIpk' does not exist on type 'Mahasiswa'!
console.log(mhs.skorIpk);
