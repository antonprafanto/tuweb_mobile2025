SLIDE 05 • PRAKTIKUM LIVE REST API (BEBAS API KEY)

Integrasi Data Publik: Cuaca Sentra Layanan UT Daerah

Mengonsumsi endpoint Open-Meteo secara real-time untuk memantau cuaca lokasi belajar mahasiswa di berbagai wilayah Indonesia.

📘 Panduan Mahasiswa Awam: Uji Coba Konsumsi Live REST API
Alat yang Digunakan: Google Chrome (Perhatikan tab Network pada DevTools F12 untuk melihat paket HTTP nyata).
Langkah Pengujian:
  1. Ubah pilihan dropdown kota sentra UT (misal: UPBJJ-UT Surabaya atau Medan).
  2. Perhatikan pemanggilan URL endpoint aktif yang menyertakan koordinat latitude & longitude secara dinamis.
  3. Amati indikator spinner berputar sejenak, lalu kartu cuaca seketika memperbarui suhu udara (°C), kecepatan angin, dan ikon kondisi cuaca secara nyata!
