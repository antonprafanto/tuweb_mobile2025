Spektrum Opsi Penyimpanan Data Mobile

Memilih media penyimpanan lokal yang tepat: Dari variabel memori RAM, LocalStorage, hingga SQLite dan Capacitor Preferences.

📘 Panduan Mahasiswa Awam: Memilih Opsi Penyimpanan Data di Smartphone
Alat yang Digunakan: Google Chrome (Buka tab Application pada DevTools F12 > lihat menu Storage / Local storage / IndexedDB).
Langkah Eksplorasi:
  1. Klik masing-masing opsi penyimpanan di panel kiri untuk membandingkan kapasitas dan perilakunya.
  2. Pahami mengapa RAM saja tidak cukup untuk aplikasi mobile (data akan terhapus saat baterai habis atau app ditutup).
  3. Untuk Tugas Tutorial 3, pilihlah LocalStorage atau Capacitor Preferences karena sangat ringan, mudah diuji, dan menjamin data catatan belajar tidak lenyap!

🎨 Diagram Arsitektur: Spektrum Spektrum Penyimpanan Mobile (Ephemeral vs Persisten)

💾 5 Media Penyimpanan Data Mobile

Klik setiap opsi penyimpanan untuk membedah karakteristik teknisnya:

1. Reactive State RAM (ref / reactive)
2. Web LocalStorage (Window API)
3. Capacitor Preferences (@capacitor/preferences) ⭐
4. IndexedDB (NoSQL Object Store)
5. SQLite Database (Relasional SQL Murni)
