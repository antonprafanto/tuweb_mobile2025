SLIDE 08 • SERIALISASI DATA KOMPLEKS

Serialisasi Array Objek: JSON.stringify() & JSON.parse()

Menyimpan struktur data tabel/koleksi riwayat belajar mahasiswa ke dalam media penyimpanan teks murni.

📘 Panduan Mahasiswa Awam: Simulasi Serialisasi JSON Data Mandiri
Alat yang Digunakan: Google Chrome / DevTools (Buka tab Application > Local storage untuk melihat string tersimpan).
Langkah Praktik:
  1. Isi formulir sesi belajar mandiri di panel kiri (pilih matkul, durasi jam, dan catatan singkat), lalu klik Simpan Sesi.
  2. Perhatikan panel kanan: Kotak atas menampilkan teks biner/string mentah hasil JSON.stringify() yang disimpan di disk.
  3. Kotak bawah menampilkan deretan kartu UI rapi yang dihasilkan dari penguraian JSON.parse(). Klik tanda silang (✕) untuk menguji operasi hapus.

⚠️ Peringatan Kesalahan: Jika Anda langsung mengetik localStorage.setItem('sesi', listSesi) tanpa JSON.stringify(), data Anda akan berubah menjadi teks rusak [object Object]!

🔍 Di Balik Layar: Serialisasi String vs Objek

1. String JSON di Storage (Hasil JSON.stringify):
{{ rawJsonString }}
2. Kartu Objek di Layar (Hasil JSON.parse):
{{ item.matkul }} ({{ item.durasi }} Jam)
{{ item.catatan }} • {{ item.tanggal }}
