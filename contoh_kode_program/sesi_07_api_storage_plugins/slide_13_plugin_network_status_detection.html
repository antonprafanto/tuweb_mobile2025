SLIDE 13 • MONITORING KONEKTIVITAS

Deteksi Status Jaringan dengan @capacitor/network

Memantau transisi online & offline secara real-time untuk memicu antrian sinkronisasi data otomatis ke server kampus.

📘 Panduan Mahasiswa Awam: Simulasi Listener Sinyal & Antrian Sinkronisasi
Alat yang Digunakan: Google Chrome (Simulator tombol atau coba ubah status Wi-Fi laptop Anda).
Langkah Eksplorasi:
  1. Klik tombol 🚫 Putuskan Sinyal (Offline): Status berubah menjadi merah dan antrian data tertunda mulai bertambah.
  2. Klik tombol 📶 Sambungkan ke Wi-Fi Kampus: Listener seketika mendeteksi sinyal pulih dan mengunggah (flush) seluruh antrian secara otomatis!
  3. Pahami bahwa pola ini menjamin mahasiswa di daerah minim sinyal tidak pernah kehilangan catatan belajar penting mereka.

🎨 Diagram Arsitektur: Event Listener Jaringan & Sinkronisasi Antrian Otomatis

📡 Listener Status Jaringan Otomatis

import { Network } from '@capacitor/network'; // 1. Dapatkan status koneksi saat ini const status = await Network.getStatus(); console.log('Online?', status.connected); console.log('Tipe:', status.connectionType); // 2. Pasang Listener Perubahan Sinyal Real-Time Network.addListener('networkStatusChange', status => { if (status.connected) { // Picu sinkronisasi data yang tertunda saat offline syncPendingOfflineData(); } });
🔄 Konsep Offline Sync Queue: Saat mahasiswa mencatat presensi saat offline di pelosok, simpan ke antrian memori lokal. Begitu listener mendeteksi sinyal internet kembali aktif, unggah otomatis seluruh antrian ke server UT!
