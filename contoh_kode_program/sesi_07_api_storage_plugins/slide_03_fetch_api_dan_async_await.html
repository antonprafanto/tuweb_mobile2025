SLIDE 03 • ASYNCHRONOUS JAVASCRIPT

Pemanggilan Data Asinkron: fetch() & async/await

Struktur penanganan request modern dengan pola pertahanan tiga lapis: try { ... } catch (e) { ... } finally { ... }.

📘 Panduan Mahasiswa Awam: Pola Eksekusi Jaringan Asinkron
Alat yang Digunakan: Google Chrome / DevTools (Tekan F12 > tab Console atau Network).
Langkah Pengujian Simulator:
  1. Klik tombol Skenario 200 OK (Sukses): Amati data berhasil dimuat ke objek resultData dan loading mati.
  2. Klik tombol Skenario 404 (Not Found): Perhatikan bahwa !res.ok memicu eksepsi yang ditangkap oleh blok catch.
  3. Klik tombol Skenario Putus Jaringan: Simulasikan saat ponsel masuk ke mode pesawat atau offline. Blok finally menjamin spinner pemuatan berhenti berputar.

🎨 Diagram Arsitektur: Pipeline Pertahanan 3 Blok try-catch-finally

💻 Pola Baku Eksekusi HTTP di Vue 3

const fetchData = async () => { isLoading.value = true; errorMessage.value = ''; try { // 1. Eksekusi Request Jaringan const res = await fetch(apiUrl); // 2. Wajib Cek response.ok (Menangkap 404/500) if (!res.ok) { throw new Error(`HTTP Error: ${res.status}`); } // 3. Parsing JSON secara Asinkron resultData.value = await res.json(); } catch (err) { // 4. Tangkap Error Jaringan / Parsing errorMessage.value = err.message; } finally { // 5. Matikan Indikator Loading (Pasti Dijalankan) isLoading.value = false; } };

🧪 Simulator Skenario Transaksi Jaringan

Picu salah satu skenario di bawah ini untuk melihat alur reaktivitasnya:

Status State Reaktif:
• isLoading: {{ isLoading }}
• errorMessage: {{ errorMessage || '(Kosong/Tidak Ada Error)' }}
• resultData: {{ resultData ? JSON.stringify(resultData) : '(null)' }}
⚠️ Jebakan Pemula: fetch() TIDAK ME-REJECT Promise jika server membalas error 404 Not Found atau 500 Server Error! Anda wajib memeriksa kondisi if (!response.ok) secara manual!
