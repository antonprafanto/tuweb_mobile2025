SLIDE 12 • SENSOR HARDWARE KAMERA

Integrasi Kamera Perangkat dengan @capacitor/camera

Menangkap foto bukti kegiatan belajar mandiri, presensi swafoto, dan dokumen tugas kuliah secara asinkron.

📸 Pola Kode TypeScript Capacitor Camera

import { Camera, CameraResultType, CameraSource } from '@capacitor/camera'; const takePicture = async () => { const photo = await Camera.getPhoto({ quality: 85, allowEditing: false, resultType: CameraResultType.DataUrl, // Cocok simpan di storage source: CameraSource.Camera }); // photo.dataUrl berisi base64 string gambar photoPreview.value = photo.dataUrl; };

💡 2 Pilihan Format Keluaran (ResultType):

1. CameraResultType.Uri: Menghasilkan URL berkas lokal (hemat memori, ideal untuk rendering cepat di UI).
2. CameraResultType.DataUrl / Base64: Menghasilkan representasi string teks gambar (sangat praktis disimpan ke LocalStorage atau dikirim via JSON REST API).
