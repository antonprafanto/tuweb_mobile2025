SLIDE 07 • PENYIMPANAN NATIVE ASINKRON

Operasi Key-Value dengan @capacitor/preferences

Menyimpan konfigurasi permanen ke sistem penyimpanan native SharedPreferences Android secara asinkron berbasis Promise.

📘 Panduan Mahasiswa Awam: Simulasi Operasi Simpan & Baca Key-Value
Alat yang Digunakan: Google Chrome (Coba tekan F5 / refresh halaman setelah menyimpan data; perhatikan data Anda tetap utuh!).
Langkah Praktik:
  1. Masukkan Kunci (cth: KODE_MATKUL) dan Nilai (cth: STSI4303).
  2. Klik tombol Simpan (mensimulasikan Preferences.set()). Data akan langsung muncul di daftar kunci aktif panel kanan.
  3. Refresh halaman peramban Anda (tekan Ctrl + R) untuk membuktikan persistensi data fisik.
