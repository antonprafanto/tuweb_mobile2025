SLIDE 10 • SENSOR HARDWARE GEOLOCATION

Integrasi Sensor GPS dengan @capacitor/geolocation

Mendapatkan koordinat lintang (*latitude*) dan bujur (*longitude*) untuk presensi lokasi belajar mahasiswa secara presisi.

📍 Pola Pemanggilan Sensor Geolocation

Eksekusi asinkron pengambilan posisi satelit GPS:

import { Geolocation } from '@capacitor/geolocation'; const getMyGPS = async () => { // 1. Dapatkan posisi GPS dengan akurasi tinggi const position = await Geolocation.getCurrentPosition({ enableHighAccuracy: true, timeout: 10000 }); const lat = position.coords.latitude; const lon = position.coords.longitude; const acc = position.coords.accuracy; };
⚙️ Izin AndroidManifest: Pastikan tag berikut telah dideklarasikan di AndroidManifest.xml:
<uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" />
