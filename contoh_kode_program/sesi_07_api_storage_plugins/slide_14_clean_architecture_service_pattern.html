Arsitektur Bersih: Pemisahan Logika via Service Layer

Memisahkan tugas: Komponen Vue hanya mengurusi tampilan UI, sementara urusan API dan Storage dikelola oleh berkas Service terpusat.

📘 Panduan Mahasiswa Awam: Memahami Pola Arsitektur Service Layer
Alat yang Digunakan: VS Code / Editor Teks (Pisahkan berkas ke dalam folder src/services/).
Prinsip Penting:
  1. Jangan menulis pemanggilan fetch() atau localStorage langsung di dalam template komponen UI secara berantakan (*spaghetti code*).
  2. Kumpulkan seluruh logika simpan, baca, dan fetch ke dalam satu objek tunggal: StudyTrackerService.
  3. Komponen UI cukup memanggil await StudyTrackerService.getAll(), sehingga kode Anda sangat bersih dan mudah dinilai penguji Tuton UT!

🎨 Diagram Arsitektur: 3 Lapisan Pola Clean Architecture (Service Pattern)

🏛️ 3 Lapisan Arsitektur (Separation of Concerns)

1. Presentation Layer (Komponen Vue SFC)

Hanya bertugas me-render template HTML, menangkap interaksi tombol pengguna, dan menampilkan variabel reaktif.

2. Service Layer (studyTrackerService.ts)

Pusat aturan bisnis! Berisi fungsi fetchWeather(), saveSession(), dan validasi data sebelum dikirim.

3. Infrastructure Adapter Layer (HTTP & Storage Drivers)

Driver teknis tingkat rendah: fetch() peramban, @capacitor/preferences, dan sensor GPS.

💡 Manfaat untuk Tugas 3: Jika dosen meminta Anda mengganti endpoint server atau mengganti LocalStorage ke SQLite, Anda cukup mengubah satu berkas Service tanpa perlu merombak seluruh tampilan komponen!

import { Preferences } from '@capacitor/preferences'; export const StudyTrackerService = { // 1. Ambil semua riwayat belajar async getAll(): Promise<any[]> { const { value } = await Preferences.get({ key: 'SESSIONS' }); return value ? JSON.parse(value) : []; }, // 2.
