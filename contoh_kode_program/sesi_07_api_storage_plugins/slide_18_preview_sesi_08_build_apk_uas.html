Menuju Sesi 08: Rilis APK Stand-alone & Sukses UAS

Mempersiapkan rilis aplikasi ke publik: Pembuatan Keystore digital, kompilasi APK Release mandiri, dan 50 Bank Soal UAS STSI4303.

🚀 3 Agenda Puncak Sesi 08 (Sesi Penutup)

1. Pembuatan Keystore & Code Signing APK

Membuat sertifikat kunci kriptografi mandiri menggunakan keytool untuk menandatangani berkas APK produksi agar dapat dipasang di smartphone siapapun tanpa peringatan bahaya.

2. Kompilasi APK Release (assembleRelease)

Menghasilkan installer APK mandiri bebas kabel USB, pemangkasan ukuran file (minification) dengan ProGuard/R8, dan optimasi zipalign.

3. 50 Bank Soal Komprehensif UAS UT

Bedah tuntas 50 soal latihan pilihan ganda & analisis studi kasus dari Modul 1 sampai Modul 9 BMP UT untuk menjamin kesiapan nilai A mahasiswa!
