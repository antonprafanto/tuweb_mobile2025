Arsitektur Offline-First & Strategi Caching

Menjaga aplikasi tetap tangguh dan bermanfaat bagi mahasiswa meskipun smartphone kehilangan sinyal internet di daerah 3T.

📘 Panduan Mahasiswa Awam: Simulasi Ketangguhan Sinyal Offline-First
Alat yang Digunakan: Google Chrome / DevTools (Bisa diuji langsung atau dicoba dengan mode Offline di tab Network).
Langkah Pengujian:
  1. Pilih mode ONLINE atau OFFLINE pada sakelar sinyal jaringan.
  2. Pilih strategi Network-First atau Cache-First.
  3. Klik tombol Picu Permintaan Data Mata Kuliah dan amati bagaimana aplikasi tetap menyajikan data dari memori cadangan lokal tanpa crash!
