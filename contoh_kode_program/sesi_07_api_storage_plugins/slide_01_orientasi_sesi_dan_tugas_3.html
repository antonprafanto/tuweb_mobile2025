🌐 Puncak Kapabilitas Aplikasi Mobile

Sebuah aplikasi mobile modern tidak dapat berdiri sendiri secara statis. Pengguna mengharapkan aplikasi yang mampu mengambil informasi terbaru dari server cloud, tetap dapat bekerja saat kehilangan sinyal internet (offline-first), serta memanfaatkan kecanggihan sensor fisik smartphone.

1. Asynchronous REST API: Mengonsumsi data eksternal via protokol HTTP menggunakan fetch() dan async/await.
2. Offline-First Storage: Menyimpan data persisten secara lokal via localStorage dan Capacitor Preferences.
3. Hardware Native Sensors: Mengakses sensor Geolocation GPS untuk pelacakan koordinat dan Camera untuk foto bukti belajar.
