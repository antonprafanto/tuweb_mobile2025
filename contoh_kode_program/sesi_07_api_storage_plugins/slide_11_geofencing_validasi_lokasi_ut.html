📐 Matematika Jarak Geografis

Bumi berbentuk bulat (*sphere*), sehingga menghitung jarak dua titik GPS tidak dapat menggunakan Teorema Pythagoras biasa. Kita menggunakan Rumus Haversine yang menghitung jarak busur lingkaran besar (*great-circle distance*).

function getDistance(lat1, lon1, lat2, lon2) { const R = 6371000; // Radius bumi dalam meter const dLat = (lat2 - lat1) * Math.PI / 180; const dLon = (lon2 - lon1) * Math.PI / 180; const a = Math.sin(dLat/2) * Math.sin(dLat/2) + Math.cos(lat1 * Math.PI / 180) * Math.cos(lat2 * Math.PI / 180) * Math.sin(dLon/2) * Math.sin(dLon/2); const c = 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1-a)); return R * c; // Hasil dalam meter }
