Keamanan API: Manajemen Token JWT & Header Authorization

Memahami cara mengamankan transaksi data private mahasiswa menggunakan JSON Web Token (JWT) dan Header Bearer.

📘 Panduan Mahasiswa Awam: Prinsip Keamanan Token JWT di Mobile App
Alat yang Digunakan: Google Chrome / DevTools (Tab Network > Headers > Request Headers > Authorization: Bearer <token>).
Langkah Pemahaman:
  1. Pelajari 3 bagian JWT yang dipisahkan oleh tanda titik: Header (Merah), Payload (Biru), dan Signature (Hijau).
  2. Ketahui bahwa Payload hanya di-encode Base64 (dapat dibaca siapa saja); jangan pernah menaruh kata sandi akun di sana!
  3. Gunakan Header Authorization: Bearer ${token} saat memanggil endpoint privat, dan tangani status 401 Unauthorized dengan mengalihkan user ke form login.

🔴 Header: Algoritma enkripsi kriptografi (HMAC SHA-256).
🔵 Payload: Data identitas (NIM, Nama, Role, Expired).
🟢 Signature: Tanda tangan digital validasi server.
⚠️ Aturan Wajib Keamanan: Bagian Payload JWT BUKANLAH DATA TERENKRIPSI RAHASIA! Jangan pernah menyimpan password akun atau nomor PIN di dalam payload JWT karena mudah di-decode oleh peretas!

🚀 Menyuntikkan Token ke Header HTTP

Pola pengiriman token ke endpoint private kampus:

const token = localStorage.getItem('JWT_TOKEN'); const response = await fetch('https://api.ut.ac.id/v1/krs/private', { method: 'GET', headers: { 'Content-Type': 'application/json', 'Authorization': `Bearer ${token}` } }); if (response.status === 401) { // Token kedaluwarsa -> Alihkan mahasiswa ke halaman Login redirectToLogin(); }
💡 Penanganan 401: Jika server membalas dengan status 401 Unauthorized, hapus token di storage dan arahkan user kembali ke form login.
