SLIDE 02 • KOMUNIKASI DATA CLIENT-SERVER

Konsep REST API: Protokol HTTP, JSON & Status Code

Memahami cara smartphone berkomunikasi dengan server cloud backend secara asinkron tanpa memuat ulang seluruh halaman.

📡 4 Kata Kerja (HTTP Methods) Utama

Pilih method HTTP di bawah untuk melihat struktur transaksi request-nya:

GET (Ambil Data) POST (Kirim Baru) PUT (Perbarui) DELETE (Hapus)
{{ currentMethod.title }}

{{ currentMethod.desc }}

Contoh Endpoint: {{ currentMethod.endpoint }}

📊 Kategori Kode Status HTTP:

🟢 2xx (Success): 200 OK (Berhasil), 201 Created (Data berhasil dibuat).
🟡 4xx (Client Error): 400 Bad Request (Input salah), 401 Unauthorized (Token tidak valid), 404 Not Found.
🔴 5xx (Server Error): 500 Internal Server Error (Server kampus crash/down).

📄 Format Pertukaran Data: JSON (JavaScript Object Notation)

Struktur respon server yang diterima oleh aplikasi mobile kita:

// HTTP/1.1 {{ currentMethod.statusCode }} // Content-Type: application/json {{ currentMethod.jsonResponse }}
💡 Prinsip Stateless: Setiap permintaan HTTP dari smartphone membawa seluruh informasi yang dibutuhkan (seperti token otentikasi). Server tidak menyimpan status sesi koneksi smartphone di memorinya!
