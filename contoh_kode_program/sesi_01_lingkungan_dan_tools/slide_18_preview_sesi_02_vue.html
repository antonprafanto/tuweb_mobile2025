Menatap Sesi 02: Mengapa Kita Harus Beralih ke Vue.js 3?

Meninggalkan kerumitan manipulasi DOM imperatif kuno dan merangkul keajaiban Reaktivitas Deklaratif modern.

💡 Mengapa Materi Ini Penting Sebelum Masuk ke Pekan Depan?
Di Sesi 01 ini, kita membuat tampilan dengan HTML dan CSS, lalu merespon aksi dengan JavaScript dasar. Namun bayangkan jika aplikasi memiliki puluhan data dinamis yang sering berubah. Menulis document.getElementById() ratusan kali akan membuat kode berantakan (Spaghetti Code). Di Sesi 02 nanti, Vue.js 3 akan menyelesaikan masalah ini!

📊 Komparasi Paradigma: Imperatif Kuno vs Deklaratif Reaktif

❌ Cara Kuno: DOM Imperatif Manual

Pengembang harus memberi perintah langkah demi langkah: cari elemen berdasarkan ID, lalu ubah teksnya secara manual satu per satu.

// Harus mencari elemen HTML satu per satu: const el1 = document.getElementById('saldoHeader'); const el2 = document.getElementById('saldoCard'); const el3 = document.getElementById('saldoFooter'); // Jika data berubah, harus ketik 3x: el1.innerText = 'Rp 250.000'; el2.innerText = 'Rp 250.000'; el3.innerText = 'Rp 250.000';
⚠️ Kelemahan: Melelahkan, rawan salah ketik ID (*null pointer error*), dan sulit dirawat pada aplikasi besar.

✅ Cara Modern: Reaktivitas Vue.js 3

Cukup definisikan data sebagai variabel reaktif (ref). Layar akan otomatis memperbarui seluruh bagian yang terhubung seketika data berubah!

// Cukup buat 1 variabel reaktif: const saldo = ref(250000); // Di template HTML cukup panggil: <h3>{{ saldo }}</h3> <p>Saldo Anda: {{ saldo }}</p> // Otomatis sinkron di semua tempat! saldo.value = 500000;
🎉 Keunggulan: Otomatis 100%, kode 5x lebih ringkas, dan fokus murni pada logika bisnis aplikasi.

🧪 Uji Langsung Efek Reaktivitas Deklaratif:

Header: Rp 2.500.000
Kartu Dashboard: Rp 2.500.000
Ringkasan Dompet: Rp 2.500.000

🚀 Bocoran Materi Sesi 02 Minggu Depan:

  • Single File Component (SFC): Memahami struktur tiga serangkai <template>, <script setup>, dan <style scoped>.
  • Vue 3 Composition API: Menguasai ref(), reactive(), dan computed() untuk mengolah data dinamis.
  • Integrasi Ionic Vue Components: Memasang <ion-button>, <ion-input>, dan <ion-card> dengan two-way data binding (v-model).
