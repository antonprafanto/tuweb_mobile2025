🚀 Menatap Sesi 02: Mengapa Kita Butuh Vue.js 3?

Di Sesi 01 ini, kita mengubah teks di layar menggunakan cara JavaScript klasik (document.getElementById().innerText = ...). Bayangkan jika aplikasi mobile memiliki puluhan input dan ratusan data, kode JavaScript Anda akan penuh dan rumit (*Spaghetti Code*)!

Cara Kuno (Imperatif):

Harus mencari elemen HTML satu per satu secara manual:

const el = document.getElementById('nilai');
el.innerText = 'Nilai Baru';

⚠️ Rawan error jika ID elemen salah ketik dan melelahkan dirawat!

Cara Modern Vue 3 (Reaktif):

Cukup deklarasikan data reaktif:

const nilai = ref('Nilai Baru');

Di HTML cukup panggil: {{ nilai }}

🎉 Layar otomatis terupdate seketika data diubah, tanpa pusing!
