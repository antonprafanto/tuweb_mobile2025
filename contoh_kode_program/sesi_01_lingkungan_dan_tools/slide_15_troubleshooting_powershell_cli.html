Protokol Pertolongan Pertama: Mengatasi Error PowerShell di Windows

Solusi tuntas untuk error PSSecurityException (running scripts is disabled) yang paling sering dihadapi mahasiswa saat mengetik perintah CLI.

💡 JANGAN PANIK! Pesan Ini Bukan Tanda Kerusakan:
Jika Anda mengetik ionic -v lalu terminal VS Code Anda berubah menjadi merah pekat dengan tulisan bahasa Inggris yang panjang, tarik napas dalam-dalam. Laptop Anda TIDAK RUSAK dan Anda TIDAK SALAH menginstal. Ini adalah fitur proteksi bawaan Windows yang memblokir eksekusi skrip otomatis.

❌ Gejala Error Klasik yang Sering Muncul:

ionic : File C:\Users\mahasiswa\AppData\Roaming\npm\ionic.ps1 cannot be loaded because running scripts is disabled on this system. For more information, see about_Execution_Policies at https:/go.microsoft.com/fwlink/?LinkID=135170. At line:1 char:1 + ionic -v + ~~~~~ + CategoryInfo : SecurityError: (:) [], PSSecurityException + FullyQualifiedErrorId : UnauthorizedAccess

✅ Solusi 1 (Rekomendasi Utama Dosen): Buka Izin Skrip Akun Anda

Jalankan satu baris perintah di bawah ini di terminal VS Code atau PowerShell Anda. Perintah ini hanya memberi izin pada akun Windows Anda saat ini secara aman tanpa mengganggu sistem komputer lainnya:

Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned
  1. Buka terminal VS Code (Ctrl + `).
  2. Tempelkan (Ctrl + V) perintah di atas lalu tekan Enter.
  3. Jika muncul pertanyaan konfirmasi [Y] Yes [A] Yes to All, cukup ketik huruf `Y` lalu tekan Enter.
  4. Ketik ulang ionic -v, dan pesan merah akan hilang seketika!

🛠️ Solusi 2 (Alternatif Tanpa Ubah Pengaturan): Beralih ke Git Bash / CMD

Jika laptop yang Anda gunakan adalah laptop kantor atau laptop pinjaman yang tidak mengizinkan perubahan kebijakan:

  1. Pada panel terminal VS Code di bagian bawah, klik tanda panah ke bawah (v) di sebelah tanda tambah (+).
  2. Pilih Git Bash atau Command Prompt (cmd) sebagai terminal default.
  3. Di terminal Git Bash atau CMD, seluruh perintah ionic, node, dan npm dapat berjalan langsung tanpa hambatan kebijakan PowerShell!
