💡 Di Mana Perintah Ini Harus Diketik?
Buka Visual Studio Code, lalu tekan kombinasi tombol Ctrl + ` (tanda kutip miring di bawah tombol ESC) untuk membuka terminal terintegrasi. Anda juga dapat menggunakan PowerShell atau Git Bash biasa!
