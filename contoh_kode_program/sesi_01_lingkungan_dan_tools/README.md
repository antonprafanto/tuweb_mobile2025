## 💡 Panduan Cepat Menjalankan Kode (Khusus Pemula):

### 1. Untuk Berkas Standalone `.html` (Semua Slide 01 s.d. 18):
* **Tidak memerlukan instalasi apa pun!**
* Cukup buka folder ini di File Explorer Windows Anda, lalu **klik dua kali (*double click*)** pada berkas `.html` yang ingin Anda pelajari.
* Berkas otomatis terbuka di Google Chrome atau Microsoft Edge.
* Tekan tombol **`F12`** pada keyboard lalu tekan tombol sakti **`Ctrl + Shift + M`** untuk melihat dalam mode simulasi smartphone!

### 2. Untuk Berkas Node.js `.js` (Opsional untuk Belajar Terminal):
* Jika Anda ingin menguji kemampuan terminal, buka Visual Studio Code.
* Tekan tombol `Ctrl + ~` untuk membuka terminal terintegrasi, lalu jalankan:
  ```powershell
  node slide_06_diagnostik_environment.js
  ```
