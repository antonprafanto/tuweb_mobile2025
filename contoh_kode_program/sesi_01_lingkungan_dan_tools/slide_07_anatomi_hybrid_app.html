⚙️ Uji Coba Komponen Anatomi:

Kondisi Saat Ini: Seluruh pilar (HTML, CSS, JS) berfungsi 100%. Tampilan indah dan tombol merespon sentuhan dengan cepat.

📖 Makna Filosofis 3 Pilar:

1. HTML (Tulang/Struktur): Tanpa HTML, tidak ada tombol, teks, maupun kartu mahasiswa.

2. CSS (Busana/Tampilan): Tanpa CSS, halaman tampak seperti dokumen Microsoft Word tahun 1995 tanpa gaya ponsel!

3. JavaScript (Saraf/Aksi): Tanpa JS, tombol secantik apa pun akan mati rasa dan tidak merespon saat diklik.
