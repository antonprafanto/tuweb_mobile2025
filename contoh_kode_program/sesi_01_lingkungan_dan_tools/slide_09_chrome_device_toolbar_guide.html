📱 3 Langkah Menguji Tampilan Ponsel di Google Chrome

Sebagai pengembang aplikasi mobile modern, Anda TIDAK PERLU mengunduh emulator Android Studio berukuran puluhan gigabyte yang membuat laptop panas. Google Chrome sudah menyediakan emulator bawaan yang sangat ringan!

Langkah 1: Buka Panel Developer Tools
Tekan tombol F12 pada keyboard Anda, atau klik kanan di mana saja lalu pilih Inspect (Periksa).
Langkah 2: Aktifkan Toggle Device Toolbar
Tekan kombinasi tombol sakti: Ctrl + Shift + M (Windows) atau Cmd + Shift + M (Mac).
Langkah 3: Pilih Model Smartphone
Di bagian atas layar peramban, pilih preset: Pixel 7, iPhone 14 Pro, atau Responsive untuk menguji rotasi layar portrait dan landscape!
