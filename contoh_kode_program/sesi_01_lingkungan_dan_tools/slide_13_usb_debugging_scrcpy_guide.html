Panduan Praktis USB Debugging & scrcpy: Uji Cepat Hemat RAM

Strategi cerdas menguji aplikasi di ponsel fisik nyata tanpa perlu menjalankan emulator Android Studio yang berat dan lambat.

💡 Mengapa Metode Ini Sangat Disukai Mahasiswa Universitas Terbuka?
Banyak mahasiswa UT belajar menggunakan laptop dengan RAM 4GB atau 8GB. Menjalankan emulator Android Studio sering membuat laptop hang dan kipas berbunyi kencang. Dengan menghubungkan ponsel fisik via USB Debugging dan menggunakan alat gratis scrcpy, penggunaan RAM laptop Anda hanya bertambah < 70 MB!

📱 3 Langkah Menghubungkan Ponsel Android Anda ke Laptop:

Langkah 1: Mengaktifkan Opsi Pengembang (Developer Options)

Secara default, Google menyembunyikan menu pengembang agar tidak tertekan secara tidak sengaja oleh pengguna awam. Untuk membukanya:

  1. Buka menu Pengaturan (Settings) di ponsel Anda.
  2. Pilih Tentang Ponsel (About Phone).
  3. Cari tulisan Nomor Bentukan (Build Number).
  4. Ketuk sebanyak 7 kali berturut-turut pada Build Number tersebut.
👆 Coba Simulasi: Ketuk Tombol "Build Number" Ini 7 Kali!
Status Ketukan: 0 / 7 kali
Langkah 2: Mengaktifkan USB Debugging & Otorisasi Komputer
  1. Kembali ke menu utama Pengaturan lalu cari Opsi Pengembang (Developer Options).
  2. Nyalakan sakelar Proses Debug USB (USB Debugging) menjadi ON.
  3. Sambungkan kabel USB dari HP ke laptop Anda.
  4. Pada layar HP akan muncul jendela dialog: "Izinkan debug USB dari komputer ini?".
  5. Centang kotak "Selalu izinkan dari komputer ini" lalu klik OK.
Langkah 3: Menjalankan scrcpy (Layar Ponsel Tampil di Laptop!)
  1. Unduh berkas zip scrcpy (misal dari rilis resmi Genymobile).
  2. Ekstrak folder tersebut di laptop Anda (contoh: di C:\tools\scrcpy).
  3. Klik dua kali pada berkas scrcpy.exe.
  4. Seketika, layar smartphone Anda akan terproyeksikan di monitor laptop dengan kendali penuh menggunakan mouse dan keyboard!
⚠️ Troubleshooting untuk Mahasiswa:
Jika layar ponsel tidak muncul saat scrcpy.exe diklik:
  • Pastikan kabel USB Anda adalah kabel data (bukan sekadar kabel pengisian baterai murah).
  • Tarik bilah notifikasi di HP Anda, ubah mode USB dari "Hanya Mengisi Daya" menjadi "Transfer File (MTP)".
