SLIDE 05 • SESI 01 (MODUL 1 BMP UT - PENYIAPAN ALAT TEMPUR)

Panduan Lengkap Penyiapan Dapur Kerja Pengembang Mobile

4 Perangkat lunak gratis yang wajib Anda pasang di laptop untuk menuntaskan seluruh tugas perkuliahan STSI4303.

❓ Pertanyaan Pemula: "Saya harus unduh dan buka tools apa dulu?"

Ikuti urutan prioritas di bawah ini. Anda tidak perlu bingung: seluruh software di bawah ini 100% GRATIS dan aman digunakan di Windows, macOS, maupun Linux:
  1. Pertama: Unduh dan pasang Visual Studio Code (alat untuk membuka dan mengetik kode program).
  2. Kedua: Unduh dan pasang Node.js versi LTS (mesin yang menjalankan JavaScript di komputer Anda).
  3. Ketiga: Unduh dan pasang Git SCM (alat pencatat revisi dan sarana mengumpulkan tugas ke GitHub).
  4. Keempat: Buka Google Chrome untuk menguji tampilan aplikasi mobile tanpa perlu emulator berat!

1. Visual Studio Code
Editor Kode Resmi Industri

Aplikasi tempat kita membaca, mengedit, dan membuat file .html, .vue, dan .ts. Ringan dan memiliki fitur auto-complete cerdas.

Ekstensi Wajib di VS Code:
• Vue - Official (Syntax highlight Vue 3)
• Prettier (Perapih format baris kode)
🌐 Unduh VS Code Resmi
🟢
2. Node.js (Versi LTS)
JavaScript Runtime Environment

Memungkinkan komputer Anda menjalankan script automasi, mengunduh library via NPM, dan menjalankan build system Ionic & Capacitor.

Tips Penting Saat Install:
Pilih versi bertuliskan "LTS" (Long Term Support, misal v20.x atau v22.x). Jangan pilih versi Current agar stabil!
🌐 Unduh Node.js LTS
🐙
3. Git SCM
Version Control & GitHub Sync

Mencatat setiap riwayat perubahan baris kode dan mengunggah tugas kuliah Anda ke repositori GitHub pribadi.

Tips Penting Saat Install:
Klik Next terus sampai selesai. Pastikan opsi "Git from command line and also 3rd-party software" terpilih.
🌐 Unduh Git SCM Resmi
🌐
4. Google Chrome
Simulator Layar Smartphone

Peramban modern yang memiliki fitur Device Toolbar untuk menguji ukuran layar HP secara instan dengan konsumsi RAM rendah.

Kelebihan untuk Awam:
Cukup klik 2x file .html untuk langsung mencoba aplikasi. Tidak perlu setup server di hari pertama!
🌐 Periksa Google Chrome

💻 "Di Mana dan Bagaimana Cara Mengetikkan Perintah Verifikasi?"

Setelah memasang VS Code, Node.js, dan Git, ikuti 3 langkah berikut untuk memastikan semuanya sudah terpasang dengan benar di komputer Anda:

Langkah 1: Buka aplikasi Visual Studio Code di laptop Anda.
Langkah 2: Buka jendela Terminal dengan menekan tombol keyboard: Ctrl + ` (tanda kutip di bawah tombol Esc) atau klik menu atas Terminal > New Terminal.
Langkah 3: Ketikkan perintah uji di bawah ini satu per satu, lalu tekan Enter:
1. Memeriksa Versi Node.js (Wajib muncul v20.x atau lebih baru):
node -v
2. Memeriksa Versi Git (Wajib muncul git version x.x.x):
git --version
3. Memeriksa Versi NPM (Pengelola Paket bawaan Node.js):
npm -v
✅ Perintah berhasil disalin ke clipboard! Silakan paste di terminal Anda.
