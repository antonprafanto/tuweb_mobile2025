Panduan cepat seluruh perintah terminal navigasi folder, alur kerja pengumpulan tugas via Git & GitHub, dan manajemen proyek Ionic.

💡 Tips Menjadi Keyboard Ninja di Terminal:
• Tombol TAB (Auto-Complete): Jangan ketik nama berkas yang panjang secara manual! Cukup ketik 2–3 huruf depan lalu tekan tombol TAB di keyboard. Terminal akan melengkapinya otomatis.
• Tombol Panah Atas (↑): Tekan tombol panah ke atas untuk memanggil kembali riwayat perintah yang baru saja Anda ketik sebelumnya!
