Alur 4 Perintah Kunci Capacitor CLI

Pipeline wajib dari kompilasi bundel web Vue hingga sinkronisasi ke proyek native Android Studio.

📘 PANDUAN PRAKTIKUM & WORKFLOW PIPELINE CLI
🛠️ Alat yang Digunakan: Terminal / PowerShell di VS Code (Ctrl + `), Node.js (npm / npx), Android Studio.
🎯 Cara Menguji Interaksi: Klik salah satu kartu tahapan di panel sebelah kiri. Perhatikan simulasi perintah dan hasil output log terminal yang muncul di panel simulator sebelah kanan.
💡 Kesalahan Paling Sering: Mahasiswa sering langsung mengetik npx cap sync tanpa menjalankan npm run build terlebih dahulu. Jika folder dist/ belum diperbarui, maka perubahan kode di Vue tidak akan pernah masuk ke dalam smartphone!
📊 Diagram Siklus Pipeline Capacitor: Dari Vue Source ke Android Studio

🚀 4 Tahap Sinkronisasi Proyek

Pilih tahapan untuk mempelajari fungsi perintah dan simulasi output terminalnya:

Langkah 1: Kompilasi Web Aset
$ npm run build
Vite mengompilasi file .vue, .ts, dan aset CSS ke dalam folder publik dist/.
Langkah 2: Tambah Platform Android (Hanya 1x di awal)
$ npx cap add android
Capacitor membuat folder native utuh android/ beserta wrapper Gradle.
Langkah 3: Sinkronisasi Aset & Plugin (Wajib Tiap Ada Perubahan)
$ npx cap sync
Menyalin berkas dist/ ke native assets folder dan mengonfigurasi gradle plugin.
Langkah 4: Luncurkan Android Studio
$ npx cap open android
Membuka Android Studio secara otomatis pada path folder android/.
