SLIDE 08 • MANIFEST SISTEM ANDROID

Anatomi Berkas AndroidManifest.xml

Kontrak resmi antara aplikasi Anda dengan sistem operasi Android: Deklarasi izin hardware, konfigurasi Activity, dan orientasi layar.

📘 PANDUAN PRAKTIKUM & DEKLARASI MANIFEST KONTRAK
🛠️ Alat yang Digunakan: Visual Studio Code / Android Studio (buka android/app/src/main/AndroidManifest.xml), Google Chrome (berkas ini).
🎯 Cara Menguji Interaksi: Centang atau hilangkan centang pada izin Kamera, Lokasi, atau Penyimpanan Media di panel kiri. Perhatikan bagaimana tag <uses-permission> ditambahkan secara dinamis ke dalam berkas XML di panel kanan.
💡 Konsekuensi Penting: Jika sebuah plugin (seperti @capacitor/camera) dipanggil dari kode JavaScript, namun izin android.permission.CAMERA belum dideklarasikan di Manifest, maka Android OS akan langsung melempar SecurityException dan aplikasi akan mengalami *crash* seketika!
📊 Diagram Hierarki Struktur XML: AndroidManifest.xml

📋 Pilih Izin & Konfigurasi Fitur

Aktifkan hak akses yang dibutuhkan aplikasi portal Anda:

INTERNET (Wajib untuk aplikasi Ionic/Capacitor)
CAMERA (Scan KTM / Presensi QR Code)
ACCESS_FINE_LOCATION (Geotagging Ujian / UT Daerah)
READ_MEDIA_IMAGES (Upload Foto Profil / Berkas Tugas)
⚠️ Aturan Android 6.0+ (API 23): Mendeklarasikan izin di berkas Manifest saja belum cukup untuk izin kategori berbahaya (*dangerous permissions* seperti Kamera & Lokasi). Mahasiswa tetap wajib meminta izin runtime secara interaktif di layar pengguna!

📄 File: AndroidManifest.xml

<?xml version="1.0" encoding="utf-8"?> <manifest xmlns:android="http://schemas.android.com/apk/res/android"> <!-- Deklarasi Hak Akses Hardware --> <uses-permission android:name="android.permission.INTERNET" /> <uses-permission android:name="android.permission.CAMERA" /> <uses-permission android:name="android.permission.ACCESS_FINE_LOCATION" /> <uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION" /> <uses-permission android:name="android.permission.READ_MEDIA_IMAGES" /> <application android:allowBackup="true" android:icon="@mipmap/ic_launcher" android:label="@string/app_name" android:roundIcon="@mipmap/ic_launcher_round" android:supportsRtl="true" android:theme="@style/AppTheme"> <activity android:configChanges="orientation|keyboardHidden|keyboard|screenSize|locale|smallestScreenSize|screenLayout|uiMode" android:name=".MainActivity" android:label="@string/title_activity_main" android:theme="@style/AppTheme.NoActionBarLaunch" android:launchMode="singleTask" android:exported="true"> <intent-filter> <action android:name="android.intent.action.MAIN" /> <category android:name="android.intent.category.LAUNCHER" /> </intent-filter> </activity> </application> </manifest>
Sitasi Sumber & Rujukan Akademik: Google Android Open Source Project: "App Manifest Overview & The <uses-permission> Element" (https://developer.android.com/guide/topics/manifest/manifest-intro). BMP STSI4303 Universitas Terbuka.
