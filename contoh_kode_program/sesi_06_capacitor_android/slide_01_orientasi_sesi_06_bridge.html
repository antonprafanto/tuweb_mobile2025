SLIDE 01 • SESI 06 (MODUL 6 & 7 BMP UT)

Orientasi Sesi 06: Capacitor Runtime Bridge & Platform Android

Melangkah dari peramban desktop menuju ekosistem perangkat native Android: Menghubungkan kode web kita dengan native SDK smartphone.

📱 Menyeberangi Jembatan Menuju Android Asli

Dari Sesi 01 hingga Sesi 05, kita telah membangun kode frontend menggunakan Vue 3, TypeScript, dan Ionic UI Toolkit di dalam peramban web desktop. Namun, tujuan akhir mata kuliah ini adalah menghasilkan aplikasi mobile sejati yang berjalan di smartphone pengguna.

🌉 Peran Kunci Capacitor:

Capacitor adalah runtime cross-platform sumber terbuka dari tim Ionic yang membungkus kode web kita ke dalam WebView native performa tinggi dan membuka akses penuh ke sensor perangkat keras.

1. Web Layer: Vue 3 SFC + Ionic Components + TypeScript (Kode yang sudah Anda buat).
2. Bridge Layer: Capacitor Runtime (Penerjemah sinyal JS ↔ Java/Kotlin).
3. Native Layer: Android OS SDK, Android Studio, Gradle, & Hardware Sensors.

🧭 4 Target Pembelajaran Sesi 06 (Sub-CPMK 6)

1. Arsitektur Capacitor Runtime Bridge

Memahami keunggulan pendekatan Source-First Capacitor dibanding Cordova klasik, serta konfigurasi capacitor.config.ts.

2. Bedah Struktur Folder android/ & Gradle

Membuka proyek di Android Studio, mengonfigurasi build.gradle, SDK target, dan ikon aplikasi di folder res/.

3. AndroidManifest.xml & Runtime Permissions

Tata kelola hak akses aplikasi: Izin kamera, lokasi GPS, penyimpanan memori, dan keamanan WebView.

4. Pengujian di Ponsel Fisik via scrcpy (Hemat RAM)

Solusi hemat memori bagi mahasiswa bertopologi RAM 4–8GB: Menjalankan aplikasi langsung di smartphone Android pribadi lewat USB Debugging.
