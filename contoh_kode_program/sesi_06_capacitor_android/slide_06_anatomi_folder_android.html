Membedah susunan direktori native hasil scaffolding Capacitor: Mengetahui letak file konfigurasi, aset web, dan kode Java.

📘 PANDUAN PRAKTIKUM & EKSPLORASI DIREKTORI NATIVE
🛠️ Alat yang Digunakan: Visual Studio Code (File Explorer), Android Studio (Project Tool Window mode Android / Project), Google Chrome (berkas ini).
🎯 Cara Menguji Interaksi: Klik salah satu nama berkas atau folder pada pohon direktori interaktif sebelah kiri. Pelajari fungsi spesifik, tingkat bahaya penyuntingan, dan contoh kode nyatanya di panel sebelah kanan.
💡 Apa yang Terjadi di Balik Layar: Di dalam folder android/app/src/main/assets/public/, seluruh bundel JavaScript dan HTML web Anda tersimpan. Saat aplikasi dibuka di HP, Android akan memuat berkas lokal ini ke dalam WebView tanpa memerlukan koneksi internet!
