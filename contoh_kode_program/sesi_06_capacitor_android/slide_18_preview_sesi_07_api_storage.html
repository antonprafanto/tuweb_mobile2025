🚀 3 Topik Utama Sesi 07 Mendatang

1. Asynchronous REST API Integration

Menghubungkan aplikasi Ionic dengan backend server Universitas Terbuka menggunakan Axios / Native HTTP Capacitor, penanganan interceptor token JWT, dan skeleton loading.

2. Offline-First Storage Persistence

Menyimpan data katalog modul mata kuliah di memori lokal smartphone via Capacitor Preferences & SQLite, sehingga aplikasi tetap berfungsi lancar saat mahasiswa kehilangan sinyal internet!

3. Integrasi Sensor Kamera & Geolocation GPS

Memotret bukti registrasi menggunakan @capacitor/camera dan memvalidasi koordinat lokasi mahasiswa saat presensi ujian daerah.
