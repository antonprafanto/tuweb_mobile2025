SLIDE 18 • JEMBATAN SESI 07 & TUGAS TUTORIAL 3

Menuju Sesi 07: Integrasi REST API, Offline Storage & Sensor

Bersiap menyongsong puncak kapabilitas aplikasi mobile: Mengonsumsi data cloud server, penyimpanan lokal offline, dan TUGAS TUTORIAL 3.

🚀 3 Topik Utama Sesi 07 Mendatang

1. Asynchronous REST API Integration

Menghubungkan aplikasi Ionic dengan backend server Universitas Terbuka menggunakan Axios / Native HTTP Capacitor, penanganan interceptor token JWT, dan skeleton loading.

2. Offline-First Storage Persistence

Menyimpan data katalog modul mata kuliah di memori lokal smartphone via Capacitor Preferences & SQLite, sehingga aplikasi tetap berfungsi lancar saat mahasiswa kehilangan sinyal internet!

3. Integrasi Sensor Kamera & Geolocation GPS

Memotret bukti registrasi menggunakan @capacitor/camera dan memvalidasi koordinat lokasi mahasiswa saat presensi ujian daerah.

PENGUMUMAN PENTING

🎯 TUGAS TUTORIAL 3 (TUTON 3) DIBUKA DI SESI 07!

Tugas Tutorial 3 adalah tugas praktikum penutup berbobot nilai terbesar sebelum Ujian Akhir Semester (UAS). Mahasiswa akan merakit aplikasi utuh yang mengombinasikan:

  • Konsumsi live REST API data perkuliahan UT.
  • Penyimpanan cache offline saat mode pesawat / tanpa sinyal.
  • Fitur scan kamera atau penangkapan foto berkas ujian.
  • Kompilasi APK debug siap pasang di smartphone fisik.
