SLIDE 07 • BUILD SYSTEM GRADLE

Konfigurasi Android SDK pada build.gradle

Memahami peranan minSdk, targetSdk, compileSdk, versionCode, dan versionName.

⚙️ Parameter Target Android SDK

OS minimum yang diizinkan menginstal aplikasi.
Versi API Android yang diuji dan dioptimalkan perilakunya.
Wajib bertambah (+1) setiap update baru ke Play Store.
Format Semantic Versioning (Mayor.Minor.Patch) untuk user.

📄 Berkas Konfigurasi Gradle

1. android/variables.gradle:
ext { minSdkVersion = {{ minSdk }} compileSdkVersion = {{ targetSdk }} targetSdkVersion = {{ targetSdk }} androidxActivityVersion = '1.8.0' androidxAppCompatVersion = '1.6.1' }
2. android/app/build.gradle:
defaultConfig { applicationId "id.ac.ut.mobileportal" minSdkVersion rootProject.ext.minSdkVersion targetSdkVersion rootProject.ext.targetSdkVersion versionCode {{ versionCode }} versionName "{{ versionName }}" testInstrumentationRunner "androidx.test.runner.AndroidJUnitRunner" }
