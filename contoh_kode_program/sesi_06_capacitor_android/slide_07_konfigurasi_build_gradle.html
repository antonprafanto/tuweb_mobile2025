SLIDE 07 • BUILD SYSTEM GRADLE

Konfigurasi Android SDK pada build.gradle

Memahami peranan minSdk, targetSdk, compileSdk, versionCode, dan versionName.

📘 PANDUAN PRAKTIKUM & MANAJEMEN VERSI GRADLE
🛠️ Alat yang Digunakan: Visual Studio Code / Android Studio (buka berkas android/app/build.gradle atau android/variables.gradle), Google Chrome (berkas ini).
🎯 Cara Menguji Interaksi: Ubah pilihan minSdk, targetSdk, atau naikkan versionCode pada formulir sebelah kiri. Amati bagaimana blok skrip Gradle di sebelah kanan beradaptasi secara otomatis.
💡 Catatan Wajib Play Store: Google Play Store mewajibkan targetSdk minimal API 34 (Android 14) untuk seluruh aplikasi baru. Setiap kali merilis pembaruan, nilai versionCode wajib dinaikkan satu angka (+1) agar tidak ditolak sistem!
📊 Diagram Spektrum Android SDK: minSdk vs targetSdk vs compileSdk

⚙️ Parameter Target Android SDK

OS minimum yang diizinkan menginstal aplikasi.
Versi API Android yang diuji dan dioptimalkan perilakunya.
Wajib naik +1 setiap kali merilis update baru.
Versi semantik yang tampil di Info Aplikasi smartphone.

📄 File: android/app/build.gradle

android { namespace "id.ac.ut.mobilelearning" compileSdk {{ targetSdk }} defaultConfig { applicationId "id.ac.ut.mobilelearning" minSdk {{ minSdk }} targetSdk {{ targetSdk }} versionCode {{ versionCode }} versionName "{{ versionName }}" testInstrumentationRunner "androidx.test.runner.AndroidJUnitRunner" } buildTypes { release { minifyEnabled false proguardFiles getDefaultProguardFile('proguard-android.txt'), 'proguard-rules.pro' } } }
✅ Best Practice Capacitor: Ubah nilai ini secara global melalui berkas android/variables.gradle agar semua plugin Capacitor otomatis menyelaraskan diri ke SDK yang sama!
Sitasi Sumber & Rujukan Akademik: Google Play Console Policy: "Meet Google Play's Target API Level Requirement" (https://developer.android.com/google/play/requirements/target-sdk) & Android Gradle Plugin DSL Specifications. BMP STSI4303 Universitas Terbuka.
