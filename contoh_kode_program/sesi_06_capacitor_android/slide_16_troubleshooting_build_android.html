Cheatsheet Diagnostik & Troubleshooting Error Android Studio & Gradle

Panduan interaktif menyelesaikan 6 eror klasik kompilasi, runtime, dan sinkronisasi Capacitor.

📘 PANDUAN PRAKTIKUM & DIAGNOSTIK MANDIRI MAHASISWA AWAM
🛠️ Alat yang Digunakan: Google Chrome (cukup klik ganda berkas ini), Android Studio (Logcat, Gradle Console, Settings), Terminal / PowerShell (npm run build, npx cap sync), Text Editor (VS Code).
🎯 Cara Menguji Interaksi:
  • Pilih salah satu dari 6 Kasus Error Klasik pada daftar sebelah kiri (atau cari kata kunci di kotak pencarian).
  • Pelajari tanda-tanda eror, pesan log konsol, dan akar penyebab teknisnya di panel kanan.
  • Klik tombol "📋 Salin Solusi / Perintah" untuk menyalin perintah perbaikan langsung ke clipboard laptop Anda!
💡 Apa yang Terjadi di Balik Layar: Sebagian besar error di Sesi 06 bukan karena salah mengetik kode Vue, melainkan ketidakcocokan lingkungan (*environment mismatch*) seperti versi Java SDK, lupa build aset ke dist/, atau kehabisan memori Gradle di laptop RAM 4GB.
