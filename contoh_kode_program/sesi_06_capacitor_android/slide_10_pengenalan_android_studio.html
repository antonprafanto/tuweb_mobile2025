📘 PANDUAN PRAKTIKUM & PENGENALAN AREA KERJA ANDROID STUDIO
🛠️ Alat yang Digunakan: Android Studio (Ladybug / Hedgehog / Iguana), Terminal (npx cap open android), Google Chrome (berkas ini).
🎯 Cara Menguji Interaksi: Klik salah satu tombol instrumen pada mockup Android Studio di bawah (Toolbar, Project View, Code Editor, Logcat). Pelajari peranan kunci tombol Run hijau (▶) dan sinkronisasi Gradle gajah (🐘).
💡 Tombol Paling Vital: Jika Anda baru saja menambahkan plugin Capacitor baru via NPM (misal @capacitor/preferences), Anda wajib menekan tombol Sync Project with Gradle Files (🐘) di pojok kanan atas Android Studio agar kode dependensi terunduh!
