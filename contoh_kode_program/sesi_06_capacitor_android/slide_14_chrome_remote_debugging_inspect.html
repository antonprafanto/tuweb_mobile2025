SLIDE 14 • TEKNIK DIAGNOSTIK WEBVIEW

Inspeksi WebView dengan chrome://inspect

Menggunakan kekuatan penuh Google Chrome DevTools desktop untuk men-debug aplikasi yang berjalan di dalam smartphone fisik.

📘 PANDUAN PRAKTIKUM & REMOTE DEBUGGING WEBVIEW
🛠️ Alat yang Digunakan: Google Chrome Desktop di Laptop, Smartphone Android Fisik yang menjalankan aplikasi Ionic/Capacitor, Kabel USB terhubung.
🎯 Cara Menguji Interaksi: Klik tab Console, Elements, atau Network pada simulator DevTools di panel kanan. Amati bagaimana Anda dapat melihat elemen DOM, pesan console.log(), dan permintaan HTTP API langsung dari ponsel nyata!
💡 Rahasia Koding Mobile: Anda tidak perlu menebak mengapa tombol di smartphone tidak berfungsi. Buka chrome://inspect, klik inspect, dan periksa tab Console untuk melihat baris error JavaScript secara persis seperti di laptop!
📊 Diagram Protokol Remote Debugging: Chrome DevTools ↔ Android WebView

🔍 Cara Mengakses DevTools Ponsel

  1. Pastikan HP terhubung ke laptop via kabel USB dengan status adb devices aktif.
  2. Buka aplikasi Ionic yang sudah di-deploy di HP.
  3. Buka peramban Google Chrome di laptop, lalu ketik di bilah URL:
    chrome://inspect/#devices
  4. Temukan nama HP Anda (misal: Samsung Galaxy) dan nama paket aplikasi (id.ac.ut.mobileportal).
  5. Klik tautan biru inspect untuk membuka jendela DevTools.
