SLIDE 04 • KONFIGURASI PROYEK

Konfigurasi Utama: capacitor.config.ts

Mendefinisikan identitas paket aplikasi Android (appId), nama tampilan di layar beranda (appName), dan folder build aset web.

📘 PANDUAN PRAKTIKUM & GENERATOR KONFIGURASI
🛠️ Alat yang Digunakan: Google Chrome (cukup klik ganda berkas ini), Visual Studio Code (buka berkas capacitor.config.ts di root proyek), Node.js CLI.
🎯 Cara Menguji Interaksi: Ubah isian pada form generator di sebelah kiri (misal ganti nama aplikasi atau ubah appId). Perhatikan pratinjau kode TypeScript di sebelah kanan akan terbarui secara reaktif dan otomatis memvalidasi format reverse domain!
💡 Apa yang Terjadi di Balik Layar: Saat perintah npx cap sync dijalankan, nilai dari berkas capacitor.config.ts ini dipetakan secara otomatis ke konfigurasi native Android: appId menjadi applicationId di Gradle, dan appName menjadi string nama aplikasi di res/values/strings.xml.

📄 Berkas Output: capacitor.config.ts

Berkas ini diletakkan di root folder proyek Ionic Anda:

import type { CapacitorConfig } from '@capacitor/cli'; const config: CapacitorConfig = { appId: '{{ appId }}', appName: '{{ appName }}', webDir: '{{ webDir }}', bundledWebRuntime: false, server: { url: '{{ serverUrl }}', cleartext: true } }; export default config;
💡 Aturan Format Reverse Domain: appId harus menggunakan format domain terbalik unik dunia (contoh: id.ac.ut.namaaplikasi). ID ini akan menjadi kunci pengenal permanen di Google Play Store dan sistem Android OS!
Sitasi Sumber & Rujukan Akademik: Capacitor Official Documentation: "Configuration Files & Properties Reference" (https://capacitorjs.com/docs/config) & Google Android Developers: "Set the Application ID" (https://developer.android.com/build/configure-app-module#set-application-id).
