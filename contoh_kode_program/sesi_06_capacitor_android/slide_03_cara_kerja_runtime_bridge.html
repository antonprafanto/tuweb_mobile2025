SLIDE 03 • ARSITEKTUR RUNTIME CAPACITOR

Cara Kerja Runtime Bridge: Pesan Dua Arah (Web ↔ Native)

Bagaimana fungsi JavaScript await Haptics.vibrate() diterjemahkan menjadi kode mesin Vibrator.vibrate() di Android OS.

🌉 Anatomi Komunikasi Dua Arah

Peramban web (Chromium WebView) berjalan di lingkungan sandbox yang terisolasi ketat. WebView tidak memiliki hak istimewa langsung untuk menyalakan senter, mengakses kamera, atau membaca GPS.

🔄 Alur Pesan Melintasi Jembatan (Bridge Pipeline):

  1. JS Invocation: Kode Vue memanggil Plugin Capacitor (mengembalikan JavaScript Promise).
  2. Serialization: Argumen dikemas ke format JSON aman dan diposkan lewat antarmuka @JavascriptInterface bawaan Android WebView.
  3. Java Execution: Thread pool latar belakang di Android mengeksekusi API SDK Android native.
  4. Callback Resolution: Hasil native dikirim balik ke WebView via evaluateJavascript() untuk me-resolve Promise di Vue.
⚡ Keunggulan Capacitor: Semua pemanggilan native bersifat Asynchronous & Non-Blocking. UI thread peramban tetap mulus 60 FPS tanpa jeda freeze!
