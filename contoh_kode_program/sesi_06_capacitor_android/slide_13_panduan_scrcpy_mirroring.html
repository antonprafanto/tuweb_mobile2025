SLIDE 13 • PRESENTASI & MIRRORING EFISIEN

Mirroring Layar Cepat & Hemat RAM dengan scrcpy

Menampilkan dan mengontrol layar HP Android langsung di layar laptop tanpa lag dan hanya memakan RAM < 70MB.

📘 PANDUAN PRAKTIKUM & MIRRORING LAYAR PADA DEMO TUGAS UT
🛠️ Alat yang Digunakan: scrcpy (unduh gratis via Chocolatey: choco install scrcpy, Winget: winget install Genymobile.scrcpy, atau GitHub zip), Terminal / PowerShell, Kabel USB.
🎯 Cara Menguji Interaksi: Centang beberapa parameter opsi scrcpy di sebelah kiri (misal: cegah tidur layar, rekam layar MP4, atau matikan layar HP fisik). Perhatikan perintah terminal yang dihasilkan otomatis di bawahnya.
💡 Solusi Praktis Ujian / Presentasi: Mahasiswa dapat mengendalikan smartphone Android cukup menggunakan keyboard dan mouse laptop Anda! Mengetik input teks formulir panjang menjadi jauh lebih cepat daripada mengetik di keyboard sentuh HP.
📊 Diagram Alur Data scrcpy: Proyeksi Video H.264 Berlatensi Rendah via USB

⚡ Fitur Unggulan scrcpy untuk Mahasiswa UT

  • Ringan & Bebas Iklan: Dibuat dengan C/Java murni oleh Genymobile, tidak membutuhkan root pada HP.
  • Latensi Sangat Rendah: Hanya 35–70 ms pada resolusi native 60 FPS.
  • Interaksi Dua Arah: Mengetik pesan lewat keyboard PC dan mengklik antarmuka dengan mouse laptop!
  • Perekaman Video Demo Tugas: Dapat merekam layar langsung menjadi berkas MP4 untuk bukti tugas tutorial.
