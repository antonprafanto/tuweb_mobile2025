🛠️ Alat yang Digunakan: Google Chrome (cukup klik ganda berkas ini), Smartphone Android Fisik + Kabel USB, Terminal / PowerShell, DevTools (F12).
🎯 Cara Menguji Interaksi:
  1. Perhatikan kartu ENVIRONMENT STATUS: Halaman ini otomatis mendeteksi apakah Anda membuka berkas di peramban web atau di dalam native Android APK.
  2. Klik tombol 📳 Uji Haptic Vibrate, 📋 Uji Salin Clipboard, atau 🔌 Simulasikan Status Jaringan.
  3. Amati konsol kabel (stream log) di sebelah kanan yang merekam paket request dan response JSON-RPC secara transparan!
💡 Apa yang Terjadi di Balik Layar: Kode ini menerapkan pola Progressive Fallback: jika dijalankan di ponsel fisik dengan Capacitor, getaran haptik asli akan aktif. Jika dibuka di Chrome desktop biasa, kode akan menggunakan Web Vibration API atau mencetak log fallback yang anggun tanpa menyebabkan aplikasi crash!
