Optimasi Aset: Format WebP & Modular Tree-Shaking

Menjaga bobot aplikasi tetap seringan kapas agar proses download APK cepat dan pemuatan halaman instan.

📘 Panduan Belajar Mahasiswa (Ramah Pemula):

🎯 Sasaran Konsep: Memahami dua pilar optimasi sisi web: kompresi format gambar WebP (hemat 30%–76% bandwidth) dan eliminasi kode pustaka yang tidak terpakai melalui ES Module Tree-Shaking pada bundler Vite/Rollup.

🛠️ Alat yang Digunakan: Google Chrome, DevTools (F12 → Tab Network untuk inspeksi transfer size), Visual Studio Code, dan Bundler Vite.

📋 Urutan Pengujian Mandiri: 1. Buka modul ini di Chrome; 2. Pelajari angka riil perbandingan logo PNG vs WebP; 3. Pahami perbedaan sintaks import monolitik (salah) vs import selektif (benar) untuk Ionicons!

🖼️ Kompresi Gambar: PNG vs WebP

Format gambar lawas seperti PNG dan JPEG memakan kapasitas memori yang besar. Standar industri mobile modern mewajibkan format WebP buatan Google yang menghasilkan kualitas visual identik namun ukuran berkas 30%–50% lebih kecil.

Logo Kampus UT (PNG Asli): 840 KB
Logo Kampus UT (Format WebP): 195 KB (Hemat 76%)

🌲 Teknik Modular Tree-Shaking pada Ionicons

Hindari mengimpor seluruh paket pustaka jika hanya butuh 2 ikon:

// SALAH (Mengimpor 1.400+ Ikon Sekaligus = +2.2 MB) import * as allIcons from 'ionicons/icons';
// BENAR (Tree-Shaking: Hanya bundel 2 ikon = +8 KB) import { bookOutline, personCircle } from 'ionicons/icons';
💡 Hasil Nyata: Bundel web yang ramping menjamin waktu boot aplikasi (*cold start*) pada smartphone pengguna turun dari 3.2 detik menjadi hanya 0.8 detik!
