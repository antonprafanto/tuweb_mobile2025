SLIDE 07 • OPTIMASI UKURAN & PROTEKSI KODE

Optimasi Ukuran & Penyamaran Kode dengan R8 / ProGuard

Memangkas ukuran berkas APK hingga 50% lebih ramping dan melindungi logika aplikasi dari ancaman reverse engineering.

🛡️ 3 Peran Vital Mesin R8 di Android

1. Dead Code Shrinking:
Menghapus ribuan method dan class library yang diimpor namun tidak pernah dipanggil di kode Anda.
2. Name Obfuscation (Penyamaran):
Mengubah nama variabel dan method yang bermakna (seperti kalkulasiNilaiIPK()) menjadi huruf pendek acak (a.b.c()) agar tidak bisa dibaca pembajak.
3. Resource Shrinking:
Menyingkirkan aset gambar dan string yang tidak pernah direferensikan dalam kode XML/Java.

🔍 Simulasi Hasil Reverse Engineering (Decompile)

Sebelum R8 (Kode Mudah Dicuri):
public class MahasiswaValidator { public boolean verifikasiNilai(int sks, double ipk) { return ipk >= 2.0 && sks >= 144; } }
Setelah R8 Obfuscation (Aman Terlindungi):
public class a { public boolean a(int i, double d) { return d >= 2.0 && i >= 144; } }
