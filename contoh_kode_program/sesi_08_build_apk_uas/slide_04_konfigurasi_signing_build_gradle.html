SLIDE 04 • KONFIGURASI GRADLE RELEASE

Konfigurasi signingConfigs pada android/app/build.gradle

Menginstruksikan Gradle untuk menandatangani APK release secara otomatis menggunakan berkas Keystore Anda.

⚙️ Parameter Penandatanganan Otomatis

Letakkan berkas ut_mobile_release.keystore Anda di dalam folder android/app/, lalu buka berkas android/app/build.gradle untuk mendaftarkan blok signingConfigs.

🔑 storeFile: Lokasi relatif berkas keystore (di dalam folder app/).
🔐 storePassword: Kata sandi brankas keystore.
🏷️ keyAlias: Nama alias kunci pengembang di dalam keystore.
🔒 keyPassword: Kata sandi khusus untuk alias tersebut.
🛡️ Best Practice: Jangan commit password asli ke GitHub publik! Simpan password pada berkas lokal gradle.properties yang di-ignore oleh Git.

📄 Kode: android/app/build.gradle

android { ... signingConfigs { release { storeFile file("ut_mobile_release.keystore") storePassword "KataSandiUt2026" keyAlias "ut_alias" keyPassword "KataSandiUt2026" } } buildTypes { release { signingConfig signingConfigs.release minifyEnabled true shrinkResources true proguardFiles getDefaultProguardFile('proguard-android-optimize.txt'), 'proguard-rules.pro' } } }
