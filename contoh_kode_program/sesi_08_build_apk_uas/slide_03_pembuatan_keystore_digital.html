SLIDE 03 • KRIPTOGRAFI TANDA TANGAN DIGITAL

Pembuatan Keystore Digital Mandiri dengan keytool

Membuat sertifikat kunci privat RSA 2048-bit seumur hidup untuk membubuhkan tanda tangan digital pada aplikasi Android.

📘 Panduan Belajar Mahasiswa (Ramah Pemula):

🎯 Sasaran Konsep: Menguasai pembuatan sertifikat identitas digital pengembang berbasis algoritma RSA 2048-bit dengan masa berlaku 10.000 hari (25+ tahun) menggunakan perintah bawaan Java SDK keytool.

🛠️ Alat yang Digunakan: Google Chrome (simulator generator ini), Terminal (Command Prompt / PowerShell di Windows, bash di macOS/Linux), Java JDK (Java Development Kit versi 17/21).

📋 Urutan Pengujian Mandiri: 1. Ubah teks nama berkas, alias kunci, dan nama pengembang di formulir sebelah kiri; 2. Perhatikan bagaimana perintah CLI keytool di sebelah kanan diperbarui secara instan; 3. Salin baris perintah tersebut ke terminal komputer Anda untuk memproduksi berkas .keystore asli!
