SLIDE 05 • EKSEKUSI BUILD RELEASE

Kompilasi APK Stand-alone via assembleRelease

Mengeksekusi proses kompilasi Gradle untuk menghasilkan berkas installer mandiri app-release.apk.

📘 Panduan Belajar Mahasiswa (Ramah Pemula):

🎯 Sasaran Konsep: Menguasai eksekusi kompilasi otomatis melalui Gradle Wrapper (./gradlew assembleRelease), memahami alur 5 tahapan internal build pipeline, dan mengetahui lokasi fisik berkas installer mandiri app-release.apk.

🛠️ Alat yang Digunakan: Google Chrome (simulator terminal), Terminal (PowerShell / Command Prompt), direktori android/, dan Gradle Wrapper (gradlew.bat di Windows atau ./gradlew di Linux/macOS).

📋 Urutan Pengujian Mandiri: 1. Buka berkas HTML ini di Chrome; 2. Klik tombol hijau ▶ Simulasikan Eksekusi ./gradlew assembleRelease; 3. Perhatikan runtutan task Gradle dari compileRelease hingga signReleaseBundle dan temukan path output berkas APK!

🎨 Diagram Arsitektur: 5 Tahapan Pipeline Eksekusi assembleRelease

🚀 2 Jalur Menghasilkan APK Release

Opsi 1: Lewat Terminal CLI (Lebih Cepat & Hemat RAM)
Masuk ke folder android/ lalu jalankan Gradle wrapper:
cd android
./gradlew assembleRelease (Linux/Mac) atau .\gradlew.bat assembleRelease (Windows).
Opsi 2: Lewat Menu Android Studio
Menu Build → Generate Signed Bundle / APK → Pilih APK → Arahkan ke file Keystore → Pilih varian release.
