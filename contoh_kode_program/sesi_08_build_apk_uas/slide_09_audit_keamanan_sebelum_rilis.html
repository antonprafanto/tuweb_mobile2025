📋 Lembar Periksa Audit Pra-Rilis

Centang seluruh poin audit di bawah ini:

1. Matikan seluruh console.log() data token/identitas mahasiswa.
2. Setel usesCleartextTraffic="false" (Wajib HTTPS di produksi).
3. Nonaktifkan Remote Debugging WebView di build release.
4. Cabut izin yang tidak dibutuhkan dari AndroidManifest.xml.
5. Aktifkan minifyEnabled true (Penyamaran R8 / ProGuard).
