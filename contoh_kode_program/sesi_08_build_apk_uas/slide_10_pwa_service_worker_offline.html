SLIDE 10 • DISTRIBUSI WEB MODERN (PWA)

Distribusi Web Berstandar PWA (Progressive Web Apps)

Memungkinkan aplikasi diinstal langsung ke layar beranda HP dari browser Chrome/Edge tanpa harus melewati Google Play Store.

🌐 Mengapa PWA Sangat Ideal untuk Mahasiswa UT?

Dengan teknologi PWA, satu kode basis Ionic Vue kita dapat didistribusikan lewat URL web biasa. Ketika mahasiswa membukanya di browser HP, muncul prompt otomatis "Tambahkan UT Mobile ke Layar Utama".

⚡ Instan Tanpa Kuota Besar: Ukuran instalasi hanya < 1 MB.
📴 Offline Berkat Service Worker: Skrip latar belakang menyimpan cache HTML/CSS/JS di browser.
📱 Tampilan Standalone: Bilah navigasi URL browser disembunyikan persis seperti aplikasi native!

📄 Berkas Konfigurasi: public/manifest.json
