SLIDE 10 • DISTRIBUSI WEB MODERN (PROGRESSIVE WEB APPS)

Distribusi Web Berstandar PWA & Caching Service Worker

Membangun aplikasi web mobile yang dapat dipasang di layar utama smartphone tanpa Google Play Store, hemat kuota internet, serta tetap dapat beroperasi secara penuh saat perangkat luring (offline).

🛠️ Panduan Praktik & Alat Uji Pengembang (Ramah Awam & Pemula)
1. Alat Utama yang Digunakan: Buka Google Chrome atau Microsoft Edge di PC/laptop Anda. Tekan F12 untuk membuka Chrome DevTools.
2. Tab Pengujian PWA: Masuk ke tab Application di DevTools:
  • Periksa menu Manifest di sisi kiri: memastikan logo (192x192 & 512x512), theme_color, dan mode standalone terbaca valid.
  • Periksa menu Service Workers: centang opsi Offline untuk menguji apakah aplikasi tetap bisa dibuka tanpa sinyal internet!
  • Periksa menu Cache Storage: melihat berkas HTML, CSS, dan JS yang tersimpan di memori lokal browser.
3. Uji Responsivitas Ponsel: Tekan kombinasi tombol Ctrl + Shift + M untuk mengaktifkan Device Mode (pilih resolusi iPhone 14 atau Samsung Galaxy S20).
4. Mengapa Sangat Penting untuk UT? Mahasiswa Universitas Terbuka tersebar di pelosok nusantara dengan koneksi yang fluktuatif. PWA menjamin portal pembelajaran tetap terbuka seketika bahkan saat kuota habis atau sinyal terputus!

📄 Berkas Standar PWA: Manifest & Service Worker

1. public/manifest.json (Identitas Aplikasi):
{ "short_name": "UT Mobile", "name": "Portal Pembelajaran Mobile Universitas Terbuka", "icons": [ { "src": "/assets/icon/icon-192.png", "sizes": "192x192", "type": "image/png" }, { "src": "/assets/icon/icon-512.png", "sizes": "512x512", "type": "image/png" } ], "start_url": "/", "background_color": "#FAF8F5", "theme_color": "#0284C7", "display": "standalone" }
2. public/sw.js (Logika Caching Luring):
const CACHE_NAME = 'ut-cache-v1'; const ASSETS = ['/', '/index.html', '/style.css', '/api-nilai-mhs.json']; self.addEventListener('install', (e) => { e.waitUntil(caches.open(CACHE_NAME).then(c => c.addAll(ASSETS))); }); self.addEventListener('fetch', (e) => { e.respondWith( caches.match(e.request).then(cached => cached || fetch(e.request)) ); });
