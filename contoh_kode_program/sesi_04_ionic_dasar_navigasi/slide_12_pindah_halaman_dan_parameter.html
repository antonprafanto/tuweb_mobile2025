Transisi Antar Layar: useRouter() & Pengiriman Parameter

Memprogram perpindahan dinamis dari halaman daftar menuju halaman rincian dengan membawa parameter URL (:kode).

📘 PANDUAN PRAKTIKUM & NAVIGASI PROGRAMATIK

🛠️ Alat yang Digunakan: Google Chrome / Visual Studio Code.

🎯 Cara Menguji Interaksi: 1. Pada simulator di panel kiri, klik salah satu mata kuliah (misal: "STSI4303").
2. Perhatikan simulasi transisi: URL berubah menjadi /modul/STSI4303 dan parameter :kode otomatis diekstrak serta ditampilkan pada kartu detail.
3. Klik tombol "◀ Kembali" untuk kembali ke katalog mata kuliah. Posisi daftar mata kuliah tetap utuh.

💡 Apa yang Terjadi di Balik Layar: Halaman asal memicu fungsi router.push(`/modul/${kode}`) via useRouter(). Komponen halaman tujuan memanfaatkan useRoute() untuk membaca parameter dinamis route.params.kode. Dengan membungkus pembacaan parameter di dalam computed(), data detail akan bereaksi otomatis jika parameter rute berganti.

📐 Alur Ekstraksi Parameter: useRouter().push() → URL Parameter (:kode) → useRoute().params

Unduh E-Book Modul BMP

💻 1. Halaman Pengirim (HomePage.vue)

import { useRouter } from 'vue-router';

const router = useRouter();

const bukaDetail = (kode: string) => {
  // Navigasi tumpukan dengan parameter URL
  router.push(`/modul/${kode}`);
};

💻 2. Halaman Penerima (ModulDetailPage.vue)

import { useRoute } from 'vue-router';
import { computed } from 'vue';

const route = useRoute();

// Mengambil parameter :kode dari URL aktif
const kodeModul = computed(() => {
  return route.params.kode as string;
});
💡 Tips Dosen: Gunakan computed() saat membaca route.params agar komponen otomatis merespons jika parameter URL berganti tanpa memuat ulang komponen dari awal.
