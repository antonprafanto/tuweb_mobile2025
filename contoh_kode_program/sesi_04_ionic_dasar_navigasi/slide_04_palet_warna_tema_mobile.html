Sistem Warna Semantik Ionic: 9 Warna Tema Bawaan

Menggunakan atribut color="..." tanpa perlu menulis kode CSS manual berulang kali.

📘 PANDUAN PENGUJIAN TEMA WARNA SEMANTIK

🛠️ Alat yang Digunakan: Google Chrome / Peramban Web Modern.

🎯 Cara Menguji Interaksi: 1. Amati kartu-kartu warna semantik di bawah ini. Coba klik masing-masing tombol untuk melihat efek riak sentuhan (*ripple*) yang warnanya serasi otomatis.
2. Perhatikan teks label lencana (badge) dan tombol: Ionic secara otomatis menghitung warna teks (putih atau hitam) agar rasio kontras terbaca jelas (memenuhi standar aksesibilitas WCAG).
3. Pelajari bagaimana atribut color="primary" dapat diterapkan ke beragam komponen berbeda.

💡 Apa yang Terjadi di Balik Layar: Ionic mengelola warna secara modular melalui variabel CSS (*CSS Custom Properties*) seperti --ion-color-primary dan --ion-color-primary-contrast. Saat Anda menetapkan color="success", komponen secara internal mengaktifkan kelas CSS yang mengontrol latar belakang, batas, dan teks kontras secara otomatis.

📐 Peta Spektrum: Peran Semantik Warna pada Antarmuka Mobile Ionic

🎨 Palet Warna Mobile Siap Pakai

Ionic menyediakan properti color yang secara otomatis mengatur warna latar, teks, dan kontras:

primary (Identitas Utama) Tombol Primary UT Biru Kampus
secondary (Aksen Dingin) Tombol Secondary Sub-Informasi
success (Kelulusan / Nilai A) Tombol Success Nilai A (Lulus)
warning (Peringatan / Deadline) Tombol Warning Tenggat Tugas 1
danger (Hapus / Bahaya) Tombol Danger Drop Mata Kuliah
dark (Gelap / Monokrom) Tombol Dark Mode Malam

💡 Cara Penggunaan di Template:

<!-- Tombol dengan warna semantik langsung tanpa CSS tambahan -->
<ion-button color="primary">Simpan Profil</ion-button>
<ion-button color="danger" fill="outline">Hapus Akun</ion-button>

<!-- Lencana Status Akademik -->
<ion-badge color="success">Aktif Registrasi</ion-badge>
