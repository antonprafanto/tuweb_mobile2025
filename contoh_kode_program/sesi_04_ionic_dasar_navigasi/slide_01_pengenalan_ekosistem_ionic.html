SLIDE 01 • MODUL 4 BMP UT

Transformasi Menuju Mobile: Mengenal Ekosistem Ionic Framework

Beralih dari elemen web konvensional ke komponen antarmuka yang dirancang khusus untuk kenyamanan sentuhan smartphone.

📘 PANDUAN PRAKTIKUM & EKSPLORASI MANDIRI

🛠️ Alat yang Digunakan: Google Chrome (Disarankan mengaktifkan Device Mode dengan menekan Ctrl + Shift + M untuk simulasi layar sentuh ponsel).

🎯 Cara Menguji Interaksi: 1. Bandingkan tombol HTML standar di panel kiri dengan tombol <ion-button> di panel kanan.
2. Klik kedua tombol tersebut. Perhatikan efek riak (*ripple effect*) dan ukuran target sentuhan jari (*touch target*) pada tombol Ionic.
3. Perhatikan bagaimana kartu <ion-card> otomatis mengaplikasikan jarak margin, elevasi bayangan halus, dan tipografi mobile yang ergonomis.

💡 Apa yang Terjadi di Balik Layar: Ionic Framework memanfaatkan spesifikasi Web Components (Custom Elements) modern. Elemen kustom seperti <ion-button> mengenkapsulasi CSS dan perilaku native ke dalam Shadow DOM, memungkinkan kita membangun aplikasi mobile multiplatform dengan basis kode web standar tanpa instalasi compiler native yang berat.

📐 Perbandingan Arsitektur: Elemen Web Standar vs Komponen Mobile Asli Ionic

1. ANTARMUKA WEB STANDAR (HTML BIASA)

Tampilan Datar Peramban Web

Elemen tombol dan kartu HTML bawaan peramban dirancang untuk kursor mouse desktop, tidak memiliki animasi transisi sentuhan, dan terlihat kaku di layar ponsel.

Informasi Mahasiswa

Kotak teks biasa tanpa elevasi bayangan atau lengkungan mobile.

<!-- HTML Biasa -->
<button>Simpan Data</button>
<div class="card">Teks</div>
2. ANTARMUKA MOBILE ASLI (IONIC UI)

Kenyamanan Smartphone Alami

Komponen Ionic memiliki area sentuh jari yang luas (minimal 48px), efek riak (*Material Design Ripple*), dan elevasi bayangan yang dioptimalkan untuk hardware ponsel.

📲 Tombol <ion-button> Asli Mobile STSI4303 • Universitas Terbuka Kartu <ion-card> Modern Dilengkapi elevasi visual, jarak padding ergonomis, dan adaptif terhadap tema ponsel. 
<!-- Ionic UI Components -->
<ion-button expand="block" color="primary">
  Simpan Data
</ion-button>
<ion-card>...</ion-card>
