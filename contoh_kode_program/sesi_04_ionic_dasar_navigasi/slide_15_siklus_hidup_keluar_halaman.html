🛑 Mengapa onUnmounted() Tidak Terpanggil?

Karena arsitektur Ionic bersifat Stack (Tumpukan), saat pengguna pindah ke halaman anak, halaman induk TIDAK DIHANCURKAN (unmounted). Oleh karena itu, onUnmounted() tidak akan pernah dieksekusi!

Jika Anda mengandalkan onUnmounted() untuk mematikan setInterval atau koneksi WebSocket, proses tersebut akan terus berjalan tanpa henti di memori dan menguras baterai pengguna!

💻 Solusi Bersih dengan onIonViewWillLeave

import { onIonViewWillLeave, onIonViewDidEnter } from '@ionic/vue';
import { ref } from 'vue';

let timerId: number | null = null;

// Mulai timer saat halaman aktif
onIonViewDidEnter(() => {
  timerId = window.setInterval(() => {
    cekLokasiGPS();
  }, 3000);
});

// Hentikan timer tepat saat layar ditinggalkan!
onIonViewWillLeave(() => {
  if (timerId) {
    clearInterval(timerId);
    timerId = null;
    console.log('🛑 Timer dimatikan, hemat baterai!');
  }
});
