Siklus Hidup Keluar: ionViewWillLeave vs ionViewDidLeave

Mencegah kebocoran memori (*memory leak*) dan menghentikan proses latar belakang yang boros baterai smartphone.

📘 PANDUAN PRAKTIKUM & OPTIMASI BATERAI PONSEL

🛠️ Alat yang Digunakan: Google Chrome / Simulator Ponsel.

🎯 Cara Menguji Interaksi: 1. Amati detik counter timer yang sedang aktif berjalan di panel kiri.
2. Klik tombol merah "🚪 Tinggalkan Halaman": perhatikan timer seketika berhenti berdetak (simulasi event onIonViewWillLeave mematikan interval). Daya baterai aman!
3. Klik tombol hijau "🔙 Masuk Kembali": timer melanjutkan penghitungan waktu dari titik terakhir (simulasi event onIonViewDidEnter).

💡 Apa yang Terjadi di Balik Layar: Karena halaman induk tetap dipertahankan dalam tumpukan memori (*stack caching*), hook standar Vue onUnmounted() sama sekali tidak terpanggil saat pengguna berpindah ke halaman anak. Jika Anda memiliki timer ujian online, audio pemutar materi, atau koneksi WebSocket, matikan selalu proses tersebut di dalam onIonViewWillLeave() guna mencegah kebocoran memori dan boros baterai ponsel.

🛑 Mengapa onUnmounted() Tidak Terpanggil?

Karena arsitektur Ionic bersifat Stack (Tumpukan), saat pengguna pindah ke halaman anak, halaman induk TIDAK DIHANCURKAN (unmounted). Oleh karena itu, onUnmounted() tidak akan pernah dieksekusi!

💻 Solusi Bersih dengan onIonViewWillLeave:

import { onIonViewWillLeave, onIonViewDidEnter } from '@ionic/vue';
import { ref } from 'vue';

let timerId: number | null = null;

// Mulai timer saat halaman aktif
onIonViewDidEnter(() => {
  timerId = window.setInterval(() => {
    cekLokasiGPS();
  }, 3000);
});

// Hentikan timer tepat saat layar ditinggalkan!
onIonViewWillLeave(() => {
  if (timerId) {
    clearInterval(timerId);
    timerId = null;
    console.log('🛑 Timer dimatikan, hemat baterai!');
  }
});
