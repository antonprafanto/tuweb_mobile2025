Navigasi Alami: Komponen <ion-back-button> & default-href

Mencegah aplikasi terjebak di halaman buntu ketika mahasiswa membuka tautan langsung atau melakukan refresh peramban.

📘 PANDUAN PRAKTIKUM & KEAMANAN NAVIGASI

🛠️ Alat yang Digunakan: Google Chrome / Simulator Ponsel.

🎯 Cara Menguji Interaksi: 1. Amati tombol panah "Kembali" pada toolbar ponsel di panel kiri.
2. Klik tombol "Kembali" saat mode Ada Riwayat: perhatikan notifikasi hijau melakukan router.back() ke halaman sebelumnya.
3. Klik tombol toggle di bawahnya untuk beralih ke mode Buka Langsung (Tanpa Riwayat / Deep Link), lalu klik lagi tombol "Kembali". Perhatikan bagaimana default-href="/home" menyelamatkan pengguna agar tidak terjebak di layar buntu!

💡 Apa yang Terjadi di Balik Layar: Komponen <ion-back-button> secara cerdas memeriksa tumpukan riwayat router internal. Jika aplikasi dibuka langsung dari tautan pesan chat atau tautan email kampus, tumpukan riwayat akan kosong. Atribut default-href berfungsi sebagai jaring pengaman (*fallback*) yang menjamin pengguna selalu diarahkan kembali ke beranda.

{{ notif }}
Simulasikan: {{ adaRiwayat ? 'Ada Riwayat Navigasi' : 'Buka Langsung (Tanpa Riwayat / Deep Link)' }}

🛡️ Mengapa default-href Sangat Wajib?

Ketika pengguna smartphone mengeklik tautan pengumuman dari WhatsApp kampus menuju halaman /tugas/1, peramban membuka aplikasi tanpa ada riwayat halaman sebelumnya di dalam memori stack.

  • Tanpa default-href: Tombol back tidak akan muncul sama sekali! Pengguna terjebak dan terpaksa menutup paksa aplikasi.
  • Dengan default-href="/home": Jika tidak ada tumpukan riwayat, Ionic otomatis mengarahkan pengguna kembali ke Beranda utama secara aman.

💻 Kode Standar Toolbar Mobile:

<ion-header>
  <ion-toolbar color="primary">
    <!-- Tombol Kembali di Slot Start -->
    <ion-buttons slot="start">
      <ion-back-button 
        default-href="/home"
        text="Kembali">
      </ion-back-button>
    </ion-buttons>

    <ion-title>Rincian Tugas</ion-title>
  </ion-toolbar>
</ion-header>
