🛡️ Mengapa default-href Sangat Wajib?

Ketika pengguna smartphone mengeklik tautan pengumuman dari WhatsApp kampus menuju halaman /tugas/1, peramban membuka aplikasi tanpa ada riwayat halaman sebelumnya di dalam memori stack.

  • Tanpa default-href: Tombol back tidak akan muncul sama sekali! Pengguna terjebak dan terpaksa menutup paksa aplikasi.
  • Dengan default-href="/home": Jika tidak ada tumpukan riwayat, Ionic otomatis mengarahkan pengguna kembali ke Beranda utama secara aman.

💻 Kode Standar Toolbar Mobile

<ion-header>
  <ion-toolbar color="primary">
    <!-- Tombol Kembali di Slot Start -->
    <ion-buttons slot="start">
      <ion-back-button 
        default-href="/home"
        text="Kembali">
      </ion-back-button>
    </ion-buttons>

    <ion-title>Rincian Tugas</ion-title>
  </ion-toolbar>
</ion-header>
