Fitur Magis: Adaptive Styling (Android MD vs iPhone iOS)

Satu basis kode secara cerdas menyesuaikan wujud visual sesuai standar sistem operasi masing-masing ponsel.

📘 PANDUAN PENGUJIAN ADAPTIVE STYLING

🛠️ Alat yang Digunakan: Google Chrome (Mode Simulator Ponsel Ctrl + Shift + M).

🎯 Cara Menguji Interaksi: 1. Klik tombol "🤖 Mode Android (Material Design)". Perhatikan judul toolbar merapat ke kiri, tombol dengan huruf kapital tegas dan efek ripple.
2. Klik tombol "🍏 Mode iPhone (Cupertino iOS)". Perhatikan judul toolbar otomatis bergeser ke tengah (*center-aligned*), tombol dengan font lebih membulat halus, dan komponen segment berubah gaya pil transparan khas iOS.
3. Perhatikan bahwa baris kode komponen di balik layar sama sekali tidak diubah!

💡 Apa yang Terjadi di Balik Layar: Secara default, Ionic secara cerdas membaca informasi navigator.userAgent pada perangkat pengguna. Jika perangkat terdeteksi sebagai Android, Ionic menginjeksi stylesheet Material Design (mode="md"). Jika terdeteksi sebagai perangkat Apple (iOS/iPadOS), Ionic menginjeksi stylesheet Cupertino (mode="ios"). Anda juga dapat memaksakannya secara global melalui atribut mode pada <ion-app>.
