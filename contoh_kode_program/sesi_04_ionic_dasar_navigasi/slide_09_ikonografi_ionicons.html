🎨 3 Varian Gaya Ionicons

Ionicons secara cerdas menyesuaikan tampilan berdasarkan mode platform:

  • Outline (Garis Tipis): Default tampilan iOS modern untuk kesan minimalis & bersih.
  • Filled (Solid Penuh): Tampilan tebal biasanya untuk status aktif / terpilih.
  • Sharp (Sudut Tajam): Tampilan geometris khas Material Design di platform Android.

⚙️ Pengaturan Ukuran & Warna

Ikon adalah font vektor SVG, sehingga ukuran dikontrol via font-size atau atribut size="small|large", dan warna dikontrol melalui CSS color atau atribut tema Ionic: 

<!-- Atribut Warna Resmi Ionic -->
<ion-icon name="heart" color="danger" size="large"></ion-icon>

<!-- Gaya Kustom Inline CSS -->
<ion-icon 
  name="school-outline" 
  style="font-size: 48px; color: #0284C7;">
</ion-icon>
