Konfigurasi Sistem: Integrasi Ionic Vue Router

Memahami komponen <ion-router-outlet> sebagai pengganti <router-view> untuk mempertahankan animasi geser dan tumpukan halaman.

📘 PANDUAN PRAKTIKUM & ARSITEKTUR ROUTER MOBILE

🛠️ Alat yang Digunakan: Google Chrome / Visual Studio Code.

🎯 Cara Menguji Interaksi: 1. Klik tombol tab "1. router/index.ts" untuk mempelajari pembuatan instans router dengan pustaka @ionic/vue-router.
2. Klik tombol tab "2. App.vue" untuk melihat penempatan komponen penampung wajib <ion-router-outlet /> di berkas induk aplikasi.
3. Pelajari tabel perbedaan kritis di panel kiri: mengapa pengembang tidak boleh menggunakan <router-view> standar pada aplikasi mobile Ionic.

💡 Apa yang Terjadi di Balik Layar: Pustaka @ionic/vue-router membungkus Vue Router 4 resmi dengan kemampuan mengelola tumpukan elemen halaman (*stack transitions*). Komponen <ion-router-outlet> menampung beberapa node halaman sekaligus di dalam DOM, mengatur animasi transisi geser layar, dan menyinkronkan event tombol kembali fisik (*hardware back button*) pada ponsel Android.

📐 Perbandingan Alur Penampung Layar: Vue Router Biasa vs Ionic Vue Router

⚠️ Perbedaan Krusial: Vue Router Standar vs Ionic Vue

Unsur Vue Router Biasa @ionic/vue-router
Pembuat Router createRouter() createRouter() dari @ionic/vue-router
Wadah Penampil <router-view /> <ion-router-outlet />
Dukungan Stack Tidak ada (replace) Ya (menjaga DOM & animasi)
🚨 Perhatian Penting untuk Mahasiswa:
Jika Anda tidak sengaja menggunakan <router-view> di Ionic, animasi slide iOS/Android tidak akan jalan dan tombol kembali <ion-back-button> akan kehilangan jejak riwayat! 
import { createRouter, createWebHistory } from '@ionic/vue-router';
import { RouteRecordRaw } from 'vue-router';
import HomePage from '@/views/HomePage.vue';
import ModulDetailPage from '@/views/ModulDetailPage.vue';

const routes: Array<RouteRecordRaw> = [
  { path: '/', redirect: '/home' },
  { path: '/home', component: HomePage },
  { path: '/modul/:kode', component: ModulDetailPage }
];

const router = createRouter({
  history: createWebHistory(import.meta.env.BASE_URL),
  routes
});

export default router;
<template>
  <ion-app>
    <!-- Wadah Resmi Pengelola Animasi Halaman -->
    <ion-router-outlet />
  </ion-app>
</template>

<script setup lang="ts">
import { IonApp, IonRouterOutlet } from '@ionic/vue';
</script>
