💡 Studi Kasus Praktikum Mandiri (Bahan Pengayaan Belajar)

Untuk membantu mahasiswa mempraktikkan materi pemrograman secara mandiri di komputer masing-masing sebelum mengerjakan tugas resmi di LMS UT, disediakan 3 studi kasus praktikum interaktif yang dapat dijalankan langsung di peramban web:

1. Studi Kasus Praktikum Sesi 03: Kalkulator IPK & Rekapitulasi SKS

  • Fokus Materi: Pemrograman Sisi Frontend Modern Menggunakan TypeScript & Vue.js 3 Composition API.
  • Capaian Mandiri: Memahami pembuatan antarmuka reaktif, pengetikan data statis (static typing), kalkulasi otomatis IPK menggunakan computed(), dan manipulasi data array tabel.
  • Berkas Pembelajaran Interaktif:
    • 📋 Checklist Kesiapan Praktikum TypeScript & Vue 3
    • 🎯 Aplikasi Praktikum Interaktif: Kalkulator IPK Mahasiswa UT

2. Studi Kasus Praktikum Sesi 05: Portal Registrasi KTM Digital & Form Regex

  • Fokus Materi: Perancangan Tata Letak Mobile Adaptif (Ionic Framework), Validasi Formulir, & Mode Gelap (Dark Mode).
  • Capaian Mandiri: Mampu menyusun antarmuka mobile berbasis kartu Ionic, menerapkan validasi regex email kampus dan format NIM, umpan balik interaktif toast/alert, serta CSS Variables theming.
  • Berkas Pembelajaran Interaktif:
    • 📋 Checklist Kesiapan Praktikum Form Validasi Mobile
    • 🎯 Aplikasi Praktikum Interaktif: Portal Registrasi KTM Digital

3. Studi Kasus Praktikum Sesi 07: Mobile Study Tracker & Native Storage

  • Fokus Materi: Integrasi Eksternal REST API, Penyimpanan Lokal Persisten, dan Pengujian Sensor/Plugin Capacitor.
  • Capaian Mandiri: Memahami pengambilan data API secara asinkron (fetch), penyimpanan preferensi lokal yang tidak hilang saat aplikasi ditutup, serta antarmuka sensor perangkat mobile.
  • Berkas Pembelajaran Interaktif:
    • 📋 Checklist Kesiapan Praktikum REST API & Storage
    • 🎯 Aplikasi Praktikum Interaktif: Mobile Study Tracker
