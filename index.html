💡 Panduan Penggunaan Berkas Pembelajaran (Ramah Mahasiswa Awam)

Seluruh materi pada repositori ini dirancang menggunakan konsep The Zero-Friction Courseware Framework agar mahasiswa dapat belajar dan mempraktikkan kode pemrograman mobile secara mudah, tanpa hambatan spesifikasi laptop:

CARA 1: UJI LANGSUNG DARING

Web Browser & Simulator

Gunakan portal web ini langsung! Cukup klik tombol "📱 Uji di Simulator" untuk mencoba aplikasi di berbagai ukuran smartphone, atau klik "👁️ Buka Penuh" untuk melihatnya di tab baru.

CARA 2: UJI LURING TANPA SERVER

Klik Ganda di Windows (file:///)

Bila mengunduh repositori ZIP ke komputer lokal, Anda TIDAK PERLU menginstal web server atau Node.js! Cukup klik ganda berkas .html dari File Explorer, peramban Chrome akan langsung menjalankannya.

CARA 3: UJI DI HP FISIK (RAMAH RAM)

USB Debugging & scrcpy

Untuk menguji aplikasi di smartphone Android fisik Anda tanpa membebani RAM laptop, pelajari panduan USB Debugging & scrcpy pada Sesi 01 Slide 13 yang memakan memori laptop kurang dari 70 MB!
